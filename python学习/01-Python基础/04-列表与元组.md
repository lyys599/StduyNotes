# 列表与元组

> [!abstract] 学完本篇，你要能够
- 创建、索引、切片和修改列表
- 使用排序、追加和聚合函数
- 理解元组适合固定记录

## 核心概念

- 列表可变，元组不可变
- `append`添加一个元素，`extend`展开多个元素
- `sorted`返回新列表，`list.sort`原地排序

## 与 C 语言对照

C数组长度通常固定；Python列表可动态扩容并容纳不同类型，但建模数据最好保持类型一致。

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
values = [18.2, 20.1, 19.7, 50.0, 21.3]
normal = [x for x in values if x < 40]
normal.append(22.0)
print("前三项：", normal[:3])
print("均值：", sum(normal) / len(normal))
station = ("A01", 31.2, 121.5)
print("站点编号：", station[0])
```

## 代码拆解

1. 列表推导式同时表达遍历和筛选。
2. 切片产生新列表。
3. 元组可用于存放不会随意改变的坐标记录。

## 数学建模中的用途

小规模中间结果可以先放列表；进入批量数值运算后应转为NumPy数组。

## 常见报错与易错点

- 空列表求均值会除以0。
- `append([1,2])`与`extend([1,2])`结果不同。
- 误以为 `sort()`返回排序后的列表。
