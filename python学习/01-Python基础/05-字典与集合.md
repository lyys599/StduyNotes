# 字典与集合

> [!abstract] 学完本篇，你要能够
- 用字典保存键值关系
- 安全查询、遍历和更新字典
- 用集合去重和做集合运算

## 核心概念

- 字典通过键访问值
- `dict.get`可提供默认值
- 集合元素唯一且无固定顺序

## 与 C 语言对照

C通常要用结构体、数组或手写映射；Python字典直接提供哈希映射。

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
records = ["A", "B", "A", "C", "B", "A"]
counts = {}
for name in records:
    counts[name] = counts.get(name, 0) + 1
print("频数：", counts)
print("站点集合：", sorted(set(records)))
required = {"A", "B", "C", "D"}
print("缺失站点：", required - set(records))
```

## 代码拆解

1. `get(name, 0)`避免首次出现时键不存在。
2. `set`立即去重。
3. 集合差找出应有但未出现的类别。

## 数学建模中的用途

频数统计、编码映射、参数表和字段检查都经常使用字典与集合。

## 常见报错与易错点

- 直接访问不存在的键会 `KeyError`。
- 集合无下标。
- 字典键必须可哈希，列表不能作为键。
