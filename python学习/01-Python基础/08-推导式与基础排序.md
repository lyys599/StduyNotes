# 推导式与基础排序

> [!abstract] 学完本篇，你要能够
- 读写列表和字典推导式
- 按自定义键排序
- 判断何时应改用普通循环

## 核心概念

- 推导式适合简单映射与筛选
- `key`指定排序依据
- 复杂逻辑不要压成一行

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
scores = {"甲": 82, "乙": 91, "丙": 76}
passed = {name: score for name, score in scores.items() if score >= 80}
ranking = sorted(scores.items(), key=lambda item: item[1], reverse=True)
print(passed)
print(ranking)
```

> [!example] 可运行代码
> [[python学习/13-VSCode代码/01-Python基础/08_ranking.py|打开对应 `.py` 文件]]。

## 代码拆解

1. 字典推导式同时遍历键和值。
2. `lambda item: item[1]`表示按分数排序。
3. `reverse=True`表示降序。

## 数学建模中的用途

适合快速生成特征列表、过滤参数和排序候选方案。

## 常见报错与易错点

- 过度嵌套导致不可读。
- 把匿名函数写得过于复杂。
- 忘记 `items()`会只遍历键。
