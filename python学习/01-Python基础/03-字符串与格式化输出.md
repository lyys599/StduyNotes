# 字符串与格式化输出

> [!abstract] 学完本篇，你要能够
- 使用索引、切片和常用字符串方法
- 拆分与拼接字段
- 生成规范的结果描述

## 核心概念

- 字符串不可原地修改
- 索引从0开始，负索引从末尾开始
- `split`拆分，`join`连接，`strip`去两端空白

## 与 C 语言对照

C字符串通常是字符数组；Python字符串有丰富方法且会自动管理内存，但仍要注意索引越界。

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
raw = "  A区,2026-07-26,PM2.5=43.7  "
clean = raw.strip()
region, day, value_text = clean.split(",")
value = float(value_text.split("=")[1])
report = f"{day} {region} 的PM2.5为 {value:.1f}"
print(report)
```

## 代码拆解

1. 先 `strip`去掉多余空格。
2. 第一次 `split`按逗号得到三个字段。
3. 第二次 `split`取等号右侧，再转成浮点数。

## 数学建模中的用途

真实附件中经常出现带单位、空格、编码或复合字段的文本，需要先清洗再转数值。

## 常见报错与易错点

- 切片右端不包含。
- `str.replace`返回新字符串，必须接收结果。
- `float('43.7mg')`会失败。
