# 变量、数据类型与运算

> [!abstract] 学完本篇，你要能够
- 区分整数、浮点数、字符串和布尔值
- 正确进行算术、比较和逻辑运算
- 使用 `type()`检查变量类型

## 核心概念

- Python变量是对象的名字，不需要提前声明类型
- `/`总得到浮点数，`//`是整除，`**`是乘方
- `and/or/not`组合条件

## 与 C 语言对照

C 常显式写 `int`、`double`；Python运行时决定类型。Python仍不是“没有类型”，而是动态类型。

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
sample_count = 120
missing_count = 7
missing_rate = missing_count / sample_count
qualified = missing_rate < 0.1
print(type(sample_count), type(missing_rate))
print(f"缺失率：{missing_rate:.2%}")
print("是否达到数据质量要求：", qualified)
```

## 代码拆解

1. 整数相除会得到浮点数，适合计算比例。
2. `:.2%`把小数按百分比显示并保留两位。
3. 比较表达式得到布尔值，可直接用于条件判断。

## 数学建模中的用途

样本量、比例、误差和阈值判断贯穿数据审计与模型评价。

## 常见报错与易错点

- 把数值写成字符串后不能直接做加法。
- 浮点数不宜用 `==`判断理论上的精确相等。
