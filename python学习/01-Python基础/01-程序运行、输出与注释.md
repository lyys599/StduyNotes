# 程序运行、输出与注释

> [!abstract] 学完本篇，你要能够
- 在 VS Code 中运行 `.py` 文件
- 使用 `print()`输出文本和计算结果
- 用注释记录目的而非复述代码

## 核心概念

- 程序按从上到下的顺序执行
- `print()`可以接收多个对象
- `#`后的内容不会执行

## 与 C 语言对照

C 的 `printf`需要格式占位符；Python 的 `print`和 f-string 更直接，但变量类型仍要保持合理。

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
# 第一个数学建模程序
team = "建模一队"
days = 3
print("队伍：", team)
print(f"比赛时长：{days * 24} 小时")
```

## 代码拆解

1. 字符串要放在引号中。
2. f-string用花括号把变量或表达式嵌入文本。
3. 先保存文件，再确认终端没有旧程序残留。

## 数学建模中的用途

比赛代码必须能清楚输出阶段名称、样本量、指标和保存位置，方便队友核对。

## 常见报错与易错点

- 使用中文弯引号会触发 `SyntaxError`。
- 只在交互窗口试代码而没有保存脚本，比赛时难以复现。
