# 合并、拼接与主键验证

> [!abstract] 学完本篇，你要能够
- 选择正确的连接类型
- 使用 `validate`检查键关系
- 识别合并后行数膨胀

## 核心概念

- `merge`按键横向连接
- `concat`按轴拼接
- 一对一、一对多和多对多必须事先明确

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
import pandas as pd

city = pd.DataFrame({"城市ID": [1, 2], "城市": ["甲", "乙"]})
yearly = pd.DataFrame({
    "城市ID": [1, 1, 2, 2],
    "年份": [2025, 2026, 2025, 2026],
    "指标": [10, 12, 8, 11],
})
merged = yearly.merge(
    city, on="城市ID", how="left", validate="many_to_one",
    indicator=True,
)
print(merged)
print(merged["_merge"].value_counts())
```

## 代码拆解

1. 年度表对城市表是多对一。
2. `validate`在键关系错误时立即报错。
3. `indicator`检查是否有未匹配行。

## 数学建模中的用途

C题经常有多张附件表，错误连接会悄悄复制样本并扭曲统计结果。

## 常见报错与易错点

- 不检查主键唯一性。
- 连接键类型不同。
- 默认内连接意外丢掉未匹配样本。
