# 分组聚合与透视表

> [!abstract] 学完本篇，你要能够
- 使用 `groupby`按类别统计
- 一次计算多个聚合指标
- 构造透视表比较二维分组

## 核心概念

- 分组遵循拆分—应用—合并
- `agg`可给多列多函数
- `pivot_table`处理重复组合

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
import pandas as pd

df = pd.DataFrame({
    "地区": ["甲", "甲", "乙", "乙"],
    "季度": [1, 2, 1, 2],
    "销量": [30, 45, 28, 50],
})
summary = df.groupby("地区", as_index=False).agg(
    平均销量=("销量", "mean"),
    总销量=("销量", "sum"),
    样本量=("销量", "size"),
)
table = df.pivot_table(index="地区", columns="季度", values="销量")
print(summary)
print(table)
```

## 代码拆解

1. 命名聚合让结果列名可直接用于论文。
2. `as_index=False`保留普通列。
3. 透视表将季度展开成列。

## 数学建模中的用途

地区比较、年度汇总、群体差异与数据附件重构都需要分组。

## 常见报错与易错点

- 分组后索引结构没看懂。
- 用平均值掩盖样本量差异。
- 透视时重复键导致普通 `pivot`报错。
