# 缺失、重复与异常值

> [!abstract] 学完本篇，你要能够
- 统计缺失率与重复记录
- 按业务规则处理非法值
- 使用IQR标记异常而非盲目删除

## 核心概念

- 缺失处理取决于机制和模型目的
- 重复要基于业务主键判断
- 异常点可能是真实极端事件

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
import pandas as pd

df = pd.DataFrame({"值": [10, 11, None, 12, 80, 12]})
q1, q3 = df["值"].quantile([0.25, 0.75])
iqr = q3 - q1
lower, upper = q1 - 1.5 * iqr, q3 + 1.5 * iqr
df["异常"] = ~df["值"].between(lower, upper) & df["值"].notna()
df["值_填补"] = df["值"].fillna(df["值"].median())
print(df)
```

## 代码拆解

1. 分位数忽略缺失值。
2. `between`判断正常区间，取反后得到异常。
3. 缺失填补与异常标记保留在新列，便于追溯。

## 数学建模中的用途

数据清洗必须保留规则、处理前后样本量和敏感性比较。

## 常见报错与易错点

- 先看全数据再划分训练集会泄漏。
- 遇到异常全部删除。
- 用0填所有缺失值而不说明。
