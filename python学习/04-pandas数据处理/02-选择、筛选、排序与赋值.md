# 选择、筛选、排序与赋值

> [!abstract] 学完本篇，你要能够
- 使用 `loc/iloc`选择数据
- 组合多个筛选条件
- 安全创建新列

## 核心概念

- 单列用 `df['列']`，多列用列表
- `loc`按标签，`iloc`按位置
- 链式赋值可能不生效

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
import pandas as pd

df = pd.DataFrame({
    "地区": ["甲", "乙", "丙", "丁"],
    "产量": [80, 120, 95, 140],
    "成本": [50, 90, 70, 100],
})
df["利润"] = df["产量"] - df["成本"]
selected = df.loc[(df["产量"] >= 100) & (df["利润"] > 25)]
print(selected.sort_values("利润", ascending=False))
```

## 代码拆解

1. 向量化创建利润列。
2. 每个条件加括号并用 `&`。
3. 排序默认返回新表。

## 数学建模中的用途

筛选有效样本、构造派生指标和排列候选方案是高频操作。

## 常见报错与易错点

- 写 `df[condition]['列'] = ...`触发链式赋值问题。
- 对Series使用 `and/or`。
- 排序后忘记保存结果。
