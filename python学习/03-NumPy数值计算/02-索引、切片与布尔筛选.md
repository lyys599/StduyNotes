# 索引、切片与布尔筛选

> [!abstract] 学完本篇，你要能够
- 选择数组的行、列和子矩阵
- 按条件筛选
- 理解视图与副本

## 核心概念

- 二维索引写成 `[行, 列]`
- 布尔数组可作为筛选条件
- 基础切片常返回共享内存的视图

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
import numpy as np

X = np.array([[10, 2], [15, 8], [20, 4], [25, 9]])
print("第一列：", X[:, 0])
mask = (X[:, 0] >= 15) & (X[:, 1] < 9)
selected = X[mask]
print(selected)
```

## 代码拆解

1. 冒号表示该维全部位置。
2. 多个数组条件要用 `&`或 `|`并各自加括号。
3. 布尔筛选保留条件为真的行。

## 数学建模中的用途

异常值筛选、条件抽样和满足约束的方案提取都需要布尔索引。

## 常见报错与易错点

- 对数组使用Python的 `and/or`。
- 忘记条件两侧括号。
- 切片视图被修改后原数组也变化。
