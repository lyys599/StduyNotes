# 向量化与广播

> [!abstract] 学完本篇，你要能够
- 用数组表达式替代数值循环
- 判断广播是否合理
- 完成按列标准化

## 核心概念

- 向量化把运算交给底层实现
- 广播从末尾维度比较
- 长度为列数的一维数组可按列作用于二维矩阵

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
import numpy as np

X = np.array([[10, 100], [20, 120], [30, 160]], dtype=float)
minimum = X.min(axis=0)
span = X.max(axis=0) - minimum
X_scaled = (X - minimum) / span
print(X_scaled)
```

## 代码拆解

1. 最小值和极差都是长度为2的数组。
2. 二维矩阵减一维数组时按列广播。
3. 整套标准化没有显式循环。

## 数学建模中的用途

归一化、距离计算、指标正向化和模型损失函数都应优先向量化。

## 常见报错与易错点

- 极差为0导致除零。
- 广播虽然不报错但作用在错误维度。
- 过早追求一行代码而失去可读性。
