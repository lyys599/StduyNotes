# 聚合、随机数与模拟

> [!abstract] 学完本篇，你要能够
- 沿指定轴计算统计量
- 使用现代随机数生成器
- 编写可复现蒙特卡洛模拟

## 核心概念

- 常用聚合有 `sum/mean/std/min/max/quantile`
- `default_rng(seed)`创建独立生成器
- 重复随机实验用比例估计概率

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
import numpy as np

rng = np.random.default_rng(42)
points = rng.uniform(-1, 1, size=(100_000, 2))
inside = (points[:, 0] ** 2 + points[:, 1] ** 2) <= 1
pi_estimate = 4 * inside.mean()
print(f"圆周率估计：{pi_estimate:.5f}")
```

## 代码拆解

1. 一次生成十万个二维点。
2. 布尔均值就是落入圆内的比例。
3. 固定种子后结果可复现。

## 数学建模中的用途

蒙特卡洛可估计复杂概率、传播参数不确定性和比较随机策略。

## 常见报错与易错点

- 在循环中反复新建随机生成器。
- 把随机种子当作调参手段。
- 模拟次数太少却报告很多小数。

## 独立练习

模拟两个骰子之和大于等于10的概率，并用不同模拟次数比较误差。
