# ndarray、形状与数据类型

> [!abstract] 学完本篇，你要能够
- 创建一维与二维数组
- 检查 `shape/ndim/dtype`
- 理解数组与列表的差别

## 核心概念

- NumPy数组通常只保存一种数据类型
- `shape`描述各维长度
- 二维特征矩阵常记为X，形状是样本数×特征数

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
import numpy as np

x = np.array([12, 15, 18, 21], dtype=float)
X = np.array([[1.2, 3.4], [2.0, 4.1], [3.2, 5.0]])
print(x.shape, x.ndim, x.dtype)
print(X.shape)
print("每列均值：", X.mean(axis=0))
```

## 代码拆解

1. 显式浮点类型便于后续统计。
2. `axis=0`沿行压缩，得到每列统计。
3. 打印形状是建模调试的第一习惯。

## 数学建模中的用途

机器学习输入、距离矩阵、评价矩阵和优化变量都以数组为基础。

## 常见报错与易错点

- 把 `(n,)`与 `(n,1)`混为一谈。
- 混入字符串导致整个数组变成文本类型。
- 不检查形状就矩阵相乘。
