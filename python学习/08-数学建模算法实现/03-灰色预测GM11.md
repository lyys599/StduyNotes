# 灰色预测GM(1,1)实现

> [!abstract] 学完本篇，你要能够
- 实现累加生成和参数估计
- 生成拟合与预测值
- 计算后验误差并识别适用范围

## 核心概念

- GM(1,1)适合小样本近指数趋势
- 原始序列应为正且规律相对稳定
- 滚动检验比只看拟合更重要

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
import numpy as np

x0 = np.array([12, 15, 19, 24, 30], dtype=float)
x1 = np.cumsum(x0)
z1 = -0.5 * (x1[1:] + x1[:-1])
B = np.column_stack([z1, np.ones(len(z1))])
a, b = np.linalg.lstsq(B, x0[1:], rcond=None)[0]
x1_hat = (x0[0] - b / a) * np.exp(-a * np.arange(len(x0) + 2)) + b / a
x0_hat = np.r_[x1_hat[0], np.diff(x1_hat)]
print("参数：", a, b)
print("拟合与未来：", x0_hat)
```

## 代码拆解

1. 累加生成削弱短期波动。
2. 背景值建立灰微分方程的离散近似。
3. 累积预测差分还原原序列。

## 数学建模中的用途

当样本很少且趋势单调时可作为基线，不能替代充分的时间序列验证。

## 常见报错与易错点

- 数据非正或强周期仍强行使用。
- 只报拟合误差。
- 长期外推。
