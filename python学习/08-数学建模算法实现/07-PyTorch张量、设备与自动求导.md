# PyTorch张量、设备与自动求导

> [!abstract] 学完本篇，你要能够
- 创建张量并检查形状
- 自动选择CUDA或CPU
- 使用自动求导理解训练基础

## 核心概念

- 张量类似可在GPU运行的NumPy数组
- 模型和数据必须位于同一设备
- `backward`计算梯度

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
import torch

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
x = torch.tensor([1.0, 2.0, 3.0], device=device, requires_grad=True)
loss = ((x - 2.0) ** 2).mean()
loss.backward()
print("设备：", device)
print("损失：", loss.item())
print("梯度：", x.grad.cpu().numpy())
```

只有当传统模型明显不足且样本量足够时再考虑神经网络；它不是默认首选。

## 常见报错与易错点

- CUDA可用就认为训练一定更快。
- 数据和模型设备不同。
- 把带梯度张量直接转NumPy。
