# 作用域与可变对象

> [!abstract] 学完本篇，你要能够
- 理解局部变量与全局变量
- 识别可变对象带来的副作用
- 用返回值替代隐式修改

## 核心概念

- 函数内部赋值默认创建局部名字
- 列表和字典可被原地修改
- 复制分浅拷贝与深拷贝

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
def add_total(record: dict[str, float]) -> dict[str, float]:
    result = record.copy()
    result["总分"] = result["数学"] + result["英语"]
    return result

original = {"数学": 90, "英语": 82}
updated = add_total(original)
print(original)
print(updated)
```

## 代码拆解

1. 先复制字典，避免函数悄悄改变原数据。
2. 新字段只存在于返回结果。
3. 比赛数据处理要明确是原地修改还是产生新表。

## 数学建模中的用途

复杂流水线中，隐式修改会让结果难以复现；尽量让函数输入输出清晰。

## 常见报错与易错点

- 滥用 `global`。
- 以为 `b = a`复制了列表。
- 在多个函数间共享可变全局状态。
