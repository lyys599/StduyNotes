# 异常处理与断言

> [!abstract] 学完本篇，你要能够
- 读懂Traceback
- 只捕获能够处理的异常
- 用断言检查模型前提

## 核心概念

- 异常类型说明失败类别
- `try/except/else/finally`分工不同
- `assert`用于程序内部不变量

## 与 C 语言对照

C常用返回码表示失败；Python通过异常把正常结果和错误路径分开。

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
def safe_ratio(numerator: float, denominator: float) -> float:
    if denominator == 0:
        raise ValueError("分母不能为0")
    return numerator / denominator

try:
    print(safe_ratio(7, 0))
except ValueError as error:
    print("输入检查失败：", error)
```

## 代码拆解

1. 主动抛出含业务含义的异常。
2. 只捕获 `ValueError`，不隐藏其他程序错误。
3. 错误信息告诉使用者如何修正。

## 数学建模中的用途

数据列缺失、样本为空、求解器失败时应立即停止并给出明确提示。

## 常见报错与易错点

- 使用裸 `except`吞掉所有错误。
- 捕获后继续使用无效结果。
- 把断言当作用户输入校验。
