# 模块、包与main入口

> [!abstract] 学完本篇，你要能够
- 拆分多个 `.py` 文件
- 理解导入与 `__name__`
- 设计清晰的主程序入口

## 核心概念

- 模块就是可导入的Python文件
- 导入时模块顶层代码会执行
- `if __name__ == '__main__'`保护入口

## 与 C 语言对照

C用头文件声明、源文件实现；Python模块直接通过 `import`组织。

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
from statistics import mean

def main() -> None:
    values = [10, 12, 15, 18]
    print("均值：", mean(values))

if __name__ == "__main__":
    main()
```

## 代码拆解

1. 把流程放进 `main`，减少全局变量。
2. 作为脚本运行时调用 `main`。
3. 作为模块导入时不会自动执行主流程。

## 数学建模中的用途

模拟C题通常由 `run_all.py`协调各分问脚本，函数放在 `src`目录中。

## 常见报错与易错点

- 文件名与第三方库重名，如 `pandas.py`。
- 循环导入。
- 依赖当前工作目录的脆弱相对路径。
