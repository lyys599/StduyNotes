# 假设检验的Python实现

> [!abstract] 学完本篇，你要能够
- 根据问题选择常见检验
- 计算统计量、p值和效应量
- 避免把不显著当作完全相同

## 核心概念

- 先写原假设与备择假设
- p值不是原假设为真的概率
- 效应量与区间比单独p值更有信息

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
import numpy as np
from scipy import stats

a = np.array([72, 75, 71, 78, 74, 77], dtype=float)
b = np.array([68, 70, 72, 69, 71, 70], dtype=float)
result = stats.ttest_ind(a, b, equal_var=False)
pooled = np.sqrt((a.var(ddof=1) + b.var(ddof=1)) / 2)
effect = (a.mean() - b.mean()) / pooled
print("t与p：", result.statistic, result.pvalue)
print("标准化效应量：", effect)
```

## 代码拆解

1. Welch检验不要求两组方差相等。
2. 效应量衡量差异相对波动大小。
3. 仍需检查独立性与数据生成过程。

## 数学建模中的用途

组间比较、政策前后对比和类别关联分析中常见检验必须与设计匹配。

## 常见报错与易错点

- 先看p值再决定假设。
- 对重复测量使用独立样本检验。
- 多次检验不校正。

## 独立练习

对两组数据画分布、检查异常值，做合适检验并同时报告均值差与效应量。
