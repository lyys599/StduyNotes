## 学会的判定

不要用“看完笔记”判定完成。一个主题必须依次通过：

1. **看懂**：能预测示例输出。
2. **复现**：关闭笔记后，从空白文件写出。
3. **迁移**：换数据、列名或参数仍能完成。
4. **解释**：能告诉队友输入、方法、参数、输出和局限。
5. **复现**：重新打开VS Code，一键从原始数据生成结果。
