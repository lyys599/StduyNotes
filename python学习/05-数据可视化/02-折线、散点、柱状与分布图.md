# 折线、散点、柱状与分布图

> [!abstract] 学完本篇，你要能够
- 根据分析问题选择图形
- 画折线、散点、柱状、直方和箱线图
- 避免误导性坐标与过度装饰

## 核心概念

- 折线表达有序变化
- 散点表达两个连续变量关系
- 直方和箱线图表达分布

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)
x = rng.normal(size=100)
y = 2 * x + rng.normal(scale=0.8, size=100)
fig, axes = plt.subplots(1, 2, figsize=(10, 4))
axes[0].scatter(x, y, alpha=0.7)
axes[0].set(xlabel="特征X", ylabel="目标Y", title="关系")
axes[1].hist(y, bins=12, edgecolor="white")
axes[1].set(title="目标变量分布")
fig.tight_layout()
fig.savefig("distribution.png", dpi=300)
plt.close(fig)
```

## 代码拆解

1. 两个子图分别回答关系与分布问题。
2. 透明度减轻点重叠。
3. 箱数会影响直方图观感，应做合理比较。

## 数学建模中的用途

EDA阶段至少查看目标分布、特征关系、类别差异和时间趋势。

## 常见报错与易错点

- 对无序类别使用折线。
- 柱状图截断纵轴夸大差异。
- 用饼图表达过多类别。
