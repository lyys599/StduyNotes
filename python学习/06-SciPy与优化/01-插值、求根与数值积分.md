# 插值、求根与数值积分

> [!abstract] 学完本篇，你要能够
- 使用SciPy完成一维插值
- 求非线性方程数值根
- 计算定积分并理解误差估计

## 核心概念

- 数值方法得到近似解
- 插值只在观测范围内通常更可靠
- 求解前必须检查函数和区间

## 手敲示例

先预测输出，再逐行输入；运行成功后至少修改三个值。

```python
import numpy as np
from scipy.interpolate import interp1d
from scipy.optimize import root_scalar
from scipy.integrate import quad

x = np.array([0, 1, 2, 3], dtype=float)
y = np.array([0, 1, 4, 9], dtype=float)
f = interp1d(x, y, kind="linear")
print("插值：", float(f(1.5)))
root = root_scalar(lambda z: z**2 - 2, bracket=[1, 2])
area, error = quad(lambda z: np.exp(-z**2), 0, 1)
print(root.root, area, error)
```

## 代码拆解

1. 插值函数只描述给定点之间的规则。
2. `bracket`区间两端应跨过根。
3. 积分同时返回估计值和误差。

## 数学建模中的用途

缺测补齐、反求阈值时间和累积效应计算中常见，但要说明数值假设。

## 常见报错与易错点

- 高阶插值过拟合。
- 在数据范围外盲目外推。
- 求根失败却继续使用结果。
