# 2026 竞赛规则与赛前检查清单

> [!danger] 以官方最新文件为准
> 本页依据 2026 年 7 月 25 日可查的全国组委会文件整理。赛前和提交前必须再次查看官网及本赛区通知。

## 1. 赛程

2026 年竞赛时间：

- 开始：9 月 10 日（周四）18:00；
- 结束：9 月 13 日（周日）20:00。

## 2. 独立完成与交流边界

- 竞赛期间指导教师不得提供选题、解题、资料或论文修改建议。
- 参赛队必须独立完成，不得与队外任何人讨论赛题。
- 不得在贴吧、QQ 群、微信群、直播间、知乎、小红书、CSDN、GitHub 等平台浏览、发布或讨论赛题相关内容。
- 公开资料可以依法合规检索使用，但必须引用；不要进入可能包含当届赛题讨论的交流平台。

## 3. AI 使用

官方规则允许 AI 辅助，但核心建模与分析必须由参赛队独立完成，并对原创性、真实性和准确性负责。

若使用 AI：

- [ ] 正文相应位置标注 AI 生成/辅助内容；
- [ ] 参考文献列出工具名称、版本/型号、机构、使用日期；
- [ ] 支撑材料包含 PDF 文件“AI 工具使用详情”；
- [ ] 记录工具名称和版本；
- [ ] 记录具体目的和环节；
- [ ] 保存关键提示词与回复；
- [ ] 说明采纳、验证和人工修改情况。

若未使用，按官方规定在参考文献后作未使用声明。

## 4. 论文格式要点

纸质版：

- [ ] A4，页边距上下左右至少 2.5 cm；
- [ ] 第一页承诺书，第二页编号专用页；
- [ ] 第三页摘要专用页，摘要含标题与关键词，原则上不超过一页；
- [ ] 从摘要页开始编页码，页脚居中，从 1 开始；
- [ ] 正文从第四页开始，不要目录，正文不超过 30 页；
- [ ] 正文后为附录，页数不限；
- [ ] 全文不得出现参赛者、学校或赛区身份。

电子论文：

- [ ] PDF 或 Word，建议 PDF；
- [ ] 不超过 20 MB；
- [ ] 不含承诺书和编号页，第一页必须是摘要；
- [ ] 内容和纸质版相应部分一致。

## 5. 代码与支撑材料

- [ ] 附录列出支撑材料文件清单；
- [ ] 包含全部完整、可运行源程序；
- [ ] 包含 Excel/SPSS 等交互命令；
- [ ] 包含自主查找的数据资料；
- [ ] 包含支撑结论的较大中间图表；
- [ ] RAR 或 ZIP，不超过 20 MB；
- [ ] 无身份信息；
- [ ] 代码运行结果与论文一致；
- [ ] 若无程序/支撑材料，按规范明确说明。

## 6. 引用

- [ ] 公开数据、算法、文字、图片均在正文标注；
- [ ] 参考文献完整；
- [ ] 无大篇幅照抄；
- [ ] 外部数据保留原始文件、访问时间和网址；
- [ ] AI 工具按专门格式列出。

## 7. 最终提交前

- [ ] 三人逐页交叉检查；
- [ ] 摘要数字与正文一致；
- [ ] 每问有明确答案；
- [ ] 所有图表有编号、单位和正文引用；
- [ ] 公式符号一致；
- [ ] 从干净目录复现关键结果；
- [ ] 搜索姓名、学号、学校、绝对路径；
- [ ] 检查 PDF 字体、乱码、裁切；
- [ ] 预留至少 2 小时提交缓冲；
- [ ] 保存提交成功证据。
