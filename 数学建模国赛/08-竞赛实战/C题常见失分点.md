# C 题常见失分点

## 1. 问题层面

- [ ] 预测题只做拟合，没有未来验证；
- [ ] 解释题只有黑箱分数，没有因素方向和不确定性；
- [ ] 优化题只有评分，没有决策变量与约束；
- [ ] 排序题没有解释指标和权重来源；
- [ ] 后一问使用前一问结果，却不传播误差。

## 2. 数据层面

- [ ] 多表合并产生重复行；
- [ ] 缺失和异常直接删除；
- [ ] 单位、时间粒度、主键未统一；
- [ ] 测试/未来信息参与预处理；
- [ ] 目标泄漏；
- [ ] 清洗前后样本量不报告。

## 3. 模型层面

- [ ] 只因“高级”选模型；
- [ ] 没有简单基线；
- [ ] 公式与代码不是同一个模型；
- [ ] 参数无来源；
- [ ] 训练分数当泛化性能；
- [ ] 启发式较好解写成全局最优；
- [ ] p 值、相关、特征重要性被解释为因果。

## 4. 检验层面

- [ ] 指标与问题代价不匹配；
- [ ] 时间序列随机划分；
- [ ] 分类不平衡只看准确率；
- [ ] 聚类只看肘部图；
- [ ] 只做一次局部 ±10% 扰动；
- [ ] 没有不确定性或替代模型。

## 5. 论文层面

- [ ] 摘要没有具体数值；
- [ ] 公式堆积，变量和单位不解释；
- [ ] 图表只有截图或无法复现；
- [ ] 每问结论不直接回答题目；
- [ ] 优缺点空泛；
- [ ] 引用缺失；
- [ ] 正文、附录和代码数字不一致。

## 6. 团队与提交

- [ ] 三人各做一问，最后无法拼成主线；
- [ ] 编程结果没有固定文件交接；
- [ ] 最后几小时才开始论文；
- [ ] 没有干净环境复现；
- [ ] 支撑材料缺代码或外部数据；
- [ ] 身份信息泄漏；
- [ ] AI 使用未按规定记录和披露；
- [ ] 没有提交缓冲。

## 7. 最小合格闭环

每一问至少应具备：

> 明确目标 → 数据依据 → 模型理由 → 可复现求解 → 合适指标 → 可靠性检验 → 直接结论 → 局限

如果时间不足，优先补齐闭环，不要继续添加新算法。
