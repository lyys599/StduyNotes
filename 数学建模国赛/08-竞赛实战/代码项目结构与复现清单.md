# 代码项目结构与复现清单

## 1. 推荐结构

```text
project/
├─ data/
│  ├─ raw/                 # 赛题原始数据，只读
│  ├─ external/            # 自主查找数据及来源说明
│  └─ processed/           # 清洗后数据
├─ src/
│  ├─ 01_audit.py
│  ├─ 02_clean.py
│  ├─ 03_eda.py
│  ├─ q1_model.py
│  ├─ q2_model.py
│  └─ validate.py
├─ outputs/
│  ├─ tables/
│  └─ figures/
├─ requirements.txt
├─ run_all.py
└─ README.md
```

支撑材料提交前按官方要求整理，不要把临时缓存、身份信息和无关大文件放入。

## 2. 每个脚本应做到

- 文件路径相对项目根目录；
- 固定随机种子；
- 函数有输入输出；
- 关键参数集中配置；
- 不依赖手工点击或 Notebook 前序内存；
- 输出文件名稳定；
- 错误时明确报错。

## 3. 随机性

```python
SEED = 42

import random
import numpy as np

random.seed(SEED)
np.random.seed(SEED)
```

不同库还需单独传 `random_state=SEED`。完全确定性不总能保证，应记录库版本和硬件。

## 4. requirements

```bash
python -m pip freeze > requirements.txt
```

更推荐只保留项目实际依赖及版本，避免几百个无关包。

## 5. README 最低内容

- Python 版本；
- 安装命令；
- 原始数据位置；
- 一键运行命令；

## 8. 易错点

- 只提交 Notebook，必须按特定单元顺序运行。
- 绝对路径含个人用户名。
- 手工修改输出表后贴论文。
- 缺少外部数据。
- 代码与最终论文不是同一版本。
