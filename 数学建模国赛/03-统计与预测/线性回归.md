# 线性回归

## 1. 模型与目标

$$
y_i=\beta_0+\beta_1x_{i1}+\cdots+\beta_px_{ip}+\varepsilon_i
$$

普通最小二乘选择 $\hat\beta$ 使残差平方和最小：

$$
\min_\beta\sum_{i=1}^{n}(y_i-\hat y_i)^2
$$

它既可做连续值预测，也可解释在“其他变量不变”时某变量与目标的条件线性关联。

## 2. 关键假设要分用途

若主要做预测：重点检查验证性能、非线性、异常点和数据泄漏。

若解释系数与 p 值：还要关注：

- 线性设定正确；
- $E(\varepsilon|X)=0$，没有重要遗漏和反向因果；
- 误差独立或正确处理相关结构；
- 同方差，或使用稳健标准误；
- 无完全共线性；
- 小样本精确推断常需误差近似正态。

“自变量低相关”不等于独立，也不能自动保证误差假设。

## 3. statsmodels 解释型案例

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm

rng = np.random.default_rng(42)
n = 100
df = pd.DataFrame({
    "投入": rng.uniform(10, 50, n),
    "规模": rng.uniform(1, 10, n)
})
df["产出"] = (
    5 + 2.0 * df["投入"] + 3.0 * df["规模"]
    + rng.normal(0, 8, n)
)

X = sm.add_constant(df[["投入", "规模"]])
model = sm.OLS(df["产出"], X).fit(cov_type="HC3")
print(model.summary())
```

`cov_type="HC3"` 给出异方差稳健标准误；它不修复非线性、遗漏变量或内生性。

## 4. 预测型案例

```python
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import cross_validate, KFold

X = df[["投入", "规模"]]
y = df["产出"]
cv = KFold(5, shuffle=True, random_state=42)

scores = cross_validate(
    LinearRegression(),
    X,
    y,
    cv=cv,
    scoring=["r2", "neg_mean_absolute_error"]
)

print("平均R2:", scores["test_r2"].mean())
print("平均MAE:", -scores["test_neg_mean_absolute_error"].mean())
```

## 5. 诊断

- 残差—拟合值图：非线性、异方差；
- Q-Q 图：尾部和正态性；
- 杠杆值/Cook 距离：高影响点；
- Durbin-Watson 或 Ljung-Box：有序数据残差相关；
- VIF：系数方差膨胀。

详见[[残差诊断与统计假设]]。

## 6. 论文表达

> 以线性回归作为可解释基线。系数采用 HC3 异方差稳健标准误。变量 A 的系数为……（95% CI……），表示控制其他变量后，A 每增加 1 单位，目标平均变化……。该结论为条件关联，不直接解释为因果。

## 7. 易错点

- 只报告 $R^2$，不做验证和残差诊断。
- 逐步删除所有 p 值大的变量，制造选择偏差。
- 标准化后仍按原单位解释系数。
- 高 $R^2$ 就声称模型正确或有因果。
