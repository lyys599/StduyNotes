# Bootstrap 重抽样与置信区间

## 1. 核心思想

从 $n$ 个观测中有放回抽取 $n$ 个，重复 $B$ 次；每次计算目标统计量，利用经验分布估计标准误、偏差和置信区间。

适合解析方差难求、分布复杂或希望检查结果稳定性的场景。

## 2. 均值差案例

```python
import numpy as np

rng = np.random.default_rng(42)
a = np.array([10, 12, 9, 11, 13, 14])
b = np.array([15, 14, 16, 18, 13, 17])

B = 5000
boot_diff = np.empty(B)

for i in range(B):
    a_star = rng.choice(a, size=len(a), replace=True)
    b_star = rng.choice(b, size=len(b), replace=True)
    boot_diff[i] = b_star.mean() - a_star.mean()

ci = np.quantile(boot_diff, [0.025, 0.975])
print("观测均值差:", b.mean() - a.mean())
print("百分位区间:", ci)
```

百分位区间简单但有偏和偏斜时可用 BCa。SciPy 提供 `scipy.stats.bootstrap`。

## 3. 抽样单位必须正确

- 独立样本：按行抽样。
- 配对数据：整对抽样。
- 同一人多行：按人/组抽样。
- 时间序列：不能普通打散抽样，应使用块 Bootstrap。

错误的抽样单位会破坏依赖结构并低估不确定性。

## 4. 在建模中的用途

- 回归系数稳定性；
- 特征选择频率；
- AUC、MAE、排名等指标区间；
- 综合评价排序稳定性；
- 参数敏感性和模型不确定性。

## 5. Bootstrap 不能解决

- 系统性偏差；
- 数据泄漏；
- 样本不代表总体；
- 极小样本中没有出现的重要模式；
- 错误模型结构。

## 6. 论文表达

> 以城市为抽样单位进行 5000 次 Bootstrap，避免同一城市多年份记录被拆散。报告指标中位数及 95% BCa 区间，并统计各方案排名进入前三的频率，以评估结论不确定性。

## 7. 易错点

- 对时间序列逐点随机抽样。
- 每次只重抽预测值，不重新拟合整个流程。
- 把 95% 置信区间解释为“真值有 95% 概率在此区间”。
- B 太小且未固定随机种子。
