# 卡方检验

## 1. 两类常见问题

- 独立性检验：两个类别变量是否有关联。
- 拟合优度检验：观测频数是否符合给定理论比例。

统计量：

$$
\chi^2=\sum\frac{(O-E)^2}{E}
$$

## 2. 独立性检验

```python
import pandas as pd
from scipy.stats import chi2_contingency

table = pd.DataFrame(
    [[30, 20], [10, 40]],
    index=["方案A", "方案B"],
    columns=["成功", "失败"]
)

chi2, p, dof, expected = chi2_contingency(table)
print("chi2:", chi2, "p:", p, "dof:", dof)
print("期望频数:\n", expected)
```

原假设：两个类别变量独立。

## 3. 拟合优度

```python
from scipy.stats import chisquare

observed = [50, 30, 20]
expected = [40, 35, 25]
print(chisquare(observed, f_exp=expected))
```

观测与期望总频数必须一致。

## 4. 条件与替代

- 每个观测只能落入一个格；
- 观测相互独立；
- 期望频数不能过小。

2×2 小样本或稀疏表可用 Fisher 精确检验：

```python
from scipy.stats import fisher_exact

odds_ratio, p = fisher_exact(table.values)
```

## 5. 效应量

Cramér's $V$：

$$
V=\sqrt{\frac{\chi^2}{n\min(r-1,c-1)}}
$$

p 值说明是否有关联，$V$ 说明关联强度。

## 6. 论文表达

> 地区与是否选择方案之间存在统计关联（$\chi^2=...$，$df=...$，$p=...$），Cramér's $V=...$，表明关联强度为……。标准化残差显示差异主要来自……单元格。

## 7. 易错点

- 把连续变量随意分箱，损失信息。
- 期望频数很小仍使用渐近卡方。
- 同一对象重复记录却当独立。
- 显著后不看哪个单元格贡献最大。
