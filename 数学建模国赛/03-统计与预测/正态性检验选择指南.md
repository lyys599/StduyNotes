# 正态性检验选择指南

## 1. 先问“谁需要正态”

- t/ANOVA：误差或组内分布，配对 t 看差值。
- 线性回归：用于小样本精确推断时主要看误差/残差，不要求每个自变量正态。
- ARIMA：残差正态影响高斯区间，白噪声更核心。
- MICE 回归模型：看所选条件模型假设。

不要对所有列批量检验正态后决定“能不能建模”。

## 2. 常见方法

| 方法 | 特点 |
|---|---|
| Q-Q 图 | 看偏离位置和尾部，必须使用 |
| Shapiro-Wilk | 小到中等样本常用 |
| D'Agostino K² | 基于偏度、峰度，要求一定样本量 |
| Jarque-Bera | 基于偏度、峰度，大样本常用 |
| Anderson-Darling | 对尾部较敏感，返回临界值 |
| KS | 若均值方差由同一数据估计，普通 KS 的 p 值不再是标准结果 |

## 3. Python

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

rng = np.random.default_rng(42)
x = rng.normal(0, 1, 200)

print("Shapiro:", stats.shapiro(x))
print("D'Agostino:", stats.normaltest(x))
print("Jarque-Bera:", stats.jarque_bera(x))
print("Anderson:", stats.anderson(x, dist="norm"))

stats.probplot(x, dist="norm", plot=plt)
plt.show()
```

## 4. 大样本陷阱

样本很大时，微小且无实际影响的偏离也会得到极小 p 值。应结合：

- Q-Q 图；
- 偏度、峰度；
- 模型对偏离的稳健性；
- Bootstrap/稳健标准误；
- 预测验证。

## 5. 论文表达

> 回归残差的 Q-Q 图显示中部近似线性但尾部略重。Shapiro-Wilk 在大样本下显著，因此不据此否定模型；系数推断采用 HC3 稳健标准误，并通过 Bootstrap 检查区间稳定性。

## 6. 易错点

- p>0.05 就“证明正态”。
- 对原始变量正态性代替残差诊断。
- 用估计后的均值方差直接做标准 KS 并按普通 p 值解释。
- 只看检验，不看图和样本量。
- 把正态性和独立性、同方差性混为一谈。
