# 岭回归

## 1. 目标函数

$$
\min_\beta\left[
\sum_{i=1}^{n}(y_i-\beta_0-x_i^T\beta)^2
+\lambda\sum_{j=1}^{p}\beta_j^2
\right]
$$

L2 惩罚把系数向 0 收缩但通常不精确变为 0，能降低方差并缓解共线性。截距通常不惩罚。

## 2. 何时使用

- 多个相关特征都可能有用；
- 普通回归系数随样本变化剧烈；
- 预测优先于稀疏解释；
- 特征数多或信噪比较低。

尺度决定惩罚大小，所以通常先标准化。

## 3. RidgeCV 案例

```python
import numpy as np
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import RidgeCV
from sklearn.model_selection import KFold

alphas = np.logspace(-4, 4, 100)
cv = KFold(5, shuffle=True, random_state=42)

model = make_pipeline(
    StandardScaler(),
    RidgeCV(alphas=alphas, cv=cv)
)
model.fit(X_train, y_train)

ridge = model.named_steps["ridgecv"]
print("最佳alpha:", ridge.alpha_)
print("测试R2:", model.score(X_test, y_test))
```

scikit-learn 用 `alpha` 表示 $\lambda$。值越大，收缩越强。

## 4. 如何解释

标准化后系数可比较相对影响，但岭回归系数是带偏收缩估计；不要直接套普通 OLS 的 p 值解释。若需要统计推断，使用专门方法或把岭回归定位为预测模型。

## 5. 论文表达

> VIF 显示特征间存在多重共线性，因此采用岭回归稳定系数。所有连续特征在训练折内标准化，并通过五折交叉验证在对数网格中选择惩罚参数。与 OLS 相比，岭回归验证 RMSE 降低……，且不同抽样下系数方向更稳定。

## 6. 易错点

- 未标准化就比较不同量纲变量。
- 用测试集选择 alpha。
- 认为岭回归会自动删除变量。
- 只看训练误差；$\lambda=0$ 时训练误差通常最小但未必泛化最好。
