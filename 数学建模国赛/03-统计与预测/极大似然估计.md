# 极大似然估计

## 1. 核心思想

选择参数 $\theta$，使已经观察到的数据在模型下最可能：

$$
\hat\theta=\arg\max_\theta L(\theta)
=\arg\max_\theta\prod_{i=1}^{n}f(x_i|\theta)
$$

计算时通常最大化对数似然：

$$
\ell(\theta)=\sum_{i=1}^{n}\log f(x_i|\theta)
$$

对数把连乘变为求和，数值更稳定。

## 2. 伯努利案例

若 $y_i\sim Bernoulli(p)$：

$$
L(p)=\prod_i p^{y_i}(1-p)^{1-y_i}
$$

求导可得 $\hat p=\bar y$。

```python
import numpy as np

y = np.array([1, 0, 1, 1, 0, 1])
p_hat = y.mean()
print(p_hat)
```

## 3. 数值优化案例

```python
import numpy as np
from scipy.optimize import minimize

x = np.array([2.1, 1.9, 2.4, 2.0, 2.2])

def neg_log_likelihood(params):
    mu, log_sigma = params
    sigma = np.exp(log_sigma)  # 保证sigma>0
    return (
        len(x) * np.log(sigma)
        + 0.5 * np.sum(((x - mu) / sigma) ** 2)
    )

result = minimize(
    neg_log_likelihood,
    x0=[x.mean(), np.log(x.std())]
)

mu_hat, log_sigma_hat = result.x
print(mu_hat, np.exp(log_sigma_hat))
```

取负号是因为 `minimize` 做最小化。

## 4. MLE 与 Logistic

Logistic 回归把每个样本的伯努利概率写成 $\sigma(x_i^T\beta)$，最大化：

$$
\ell(\beta)=\sum_i
\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right]
$$

常用软件会直接优化它。并非因为“最小二乘一定是非凸”才不能用；更根本的原因是伯努利响应的方差和分布结构与普通最小二乘假设不匹配。

## 5. 似然不能单独证明模型正确

更大似然通常意味着样本内拟合更好，但复杂模型天然有优势，需要 AIC/BIC、交叉验证和残差诊断约束。

## 6. 易错点

- 把似然当作参数本身的概率。
- 忘记独立性或分布设定。
- 优化收敛就认为模型合理。
- 比较不同数据或不同似然定义的原始似然值。
- 忽略局部最优、边界解和数值溢出。
