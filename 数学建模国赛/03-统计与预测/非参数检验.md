# 非参数检验

## 1. 什么时候考虑

- 等级数据；
- 小样本且严重偏态/极端值；
- 参数检验假设明显不合理；
- 研究目标本身是分布位置或随机优势。

非参数不等于“无假设”。它仍要求独立/配对结构正确；某些“中位数差异”解释还需要分布形状相似。

## 2. 方法对应

| 设计 | 方法 |
|---|---|
| 两独立组 | Mann-Whitney U |
| 两配对组 | Wilcoxon 符号秩 |
| 三个以上独立组 | Kruskal-Wallis |
| 三个以上配对条件 | Friedman |

## 3. Python

```python
import numpy as np
from scipy import stats

a = np.array([1, 2, 2, 3, 20])
b = np.array([4, 5, 5, 6, 7])

print(stats.mannwhitneyu(a, b, alternative="two-sided"))

before = np.array([10, 12, 15, 9, 11])
after = np.array([12, 13, 18, 10, 14])
print(stats.wilcoxon(after, before))

c = np.array([7, 8, 9, 8, 10])
print(stats.kruskal(a, b, c))
```

## 4. 结果解释

Mann-Whitney 更一般地比较两组随机取值的相对大小，不应在分布形状不同的情况下简单写成“中位数检验”。

报告秩效应量、概率优势或 Hodges-Lehmann 位置差，并配合箱线/ECDF。

## 5. 置换检验

若可交换性成立，可通过随机打乱组标签建立零分布。它能直接针对自定义统计量，适合竞赛中解释清楚的情形。

## 6. 论文表达

> 变量呈严重右偏且样本量较小，采用 Mann-Whitney U 检验比较两独立组。结果显示 B 组取值整体较高（$U=...$，$p=...$），概率优势/效应量为……。由于两组分布形状不同，本文不将其简单解释为中位数差异。

## 7. 易错点

- 只要“不正态”就自动换非参数。
- 配对数据用独立组检验。
- 多组检验显著后不做校正的事后比较。
- 非显著就说分布完全相同。
