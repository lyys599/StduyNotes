# 假设检验选择框架

## 1. 标准流程

1. 在看结果前写原假设 $H_0$ 和备择假设 $H_1$。
2. 明确独立/配对、变量类型、分布与方差条件。
3. 选择显著性水平 $\alpha$。
4. 计算统计量和 p 值。
5. 报告效应量与置信区间。
6. 检查多重比较、样本量和实际意义。

## 2. 快速选择

| 研究问题 | 参数方法 | 非参数/其他 |
|---|---|---|
| 单组均值与基准 | 单样本 t | 符号/置换 |
| 两独立组中心差异 | Welch t | Mann-Whitney U |
| 两次配对测量 | 配对 t | Wilcoxon 符号秩 |
| 三组以上均值 | ANOVA/Welch ANOVA | Kruskal-Wallis |
| 两个类别变量关联 | 卡方独立性 | Fisher 精确检验 |
| 分布与理论比例 | 卡方拟合优度 | 精确/模拟检验 |
| 回归系数 | t/Z/Wald | Bootstrap/稳健标准误 |

## 3. p 值是什么

p 值是在 $H_0$ 与模型假设成立时，得到当前或更极端数据的概率。它不是：

- $H_0$ 为真的概率；
- 结果由偶然造成的概率；
- 效应大小；
- 研究结论正确的概率。

## 4. 效应量与区间

样本很大时微小差异也可能显著；样本很小时重要差异也可能不显著。应同时报告：

- 均值差/中位数差；
- Cohen's $d$；
- 优势比、风险比；
- Cramér's $V$；
- 95% 置信区间。

## 5. 多重比较

一次检验 $\alpha=0.05$；做很多检验时至少一个假阳性的概率上升。常用：

- Bonferroni：保守；
- Holm：逐步校正；
- Benjamini-Hochberg：控制 FDR。

```python
from statsmodels.stats.multitest import multipletests

reject, p_adj, _, _ = multipletests(
    p_values,
    alpha=0.05,
    method="fdr_bh"
)
```

## 6. 论文表达

> 在显著性水平 0.05 下采用 Welch t 检验比较两独立组均值，同时报告均值差、95% 置信区间和 Cohen's d。对多指标检验使用 Benjamini-Hochberg 方法控制 FDR。

## 7. 易错点

- 先看数据再决定单尾检验。
- $p>0.05$ 就写“两组完全相同”。
- 连续做正态性、方差齐性和主检验，却不考虑检验功效。
- 只追求显著，不报告效应大小。
