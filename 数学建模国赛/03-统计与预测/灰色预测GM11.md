# 灰色预测 GM(1,1)

## 1. 适用边界

GM(1,1) 面向短小、非负、较平滑、近似指数单调的单变量序列。它不是“小样本万能兜底”：

- 强周期、剧烈波动、结构突变不适合；
- 长期预测误差容易迅速累积；
- 样本虽可很少，但过少时检验和泛化都很弱。

## 2. 建模步骤

原序列：

$$
X^{(0)}=(x^{(0)}(1),\ldots,x^{(0)}(n))
$$

一次累加：

$$
x^{(1)}(k)=\sum_{i=1}^{k}x^{(0)}(i)
$$

背景值：

$$
z^{(1)}(k)=\frac12[x^{(1)}(k)+x^{(1)}(k-1)]
$$

灰微分方程：

$$
x^{(0)}(k)+az^{(1)}(k)=b
$$

用最小二乘估计 $a,b$，再通过时间响应式还原。

## 3. Python 实现

```python
import numpy as np

def gm11(x0, horizon=3):
    x0 = np.asarray(x0, dtype=float)
    if len(x0) < 4 or np.any(x0 <= 0):
        raise ValueError("GM(1,1)通常要求至少4个正数")

    x1 = np.cumsum(x0)
    z1 = 0.5 * (x1[1:] + x1[:-1])
    B = np.column_stack((-z1, np.ones(len(z1))))
    Y = x0[1:]

    a, b = np.linalg.lstsq(B, Y, rcond=None)[0]
    if abs(a) < 1e-10:
        raise ValueError("发展系数过于接近0，公式数值不稳定")

    k = np.arange(len(x0) + horizon)
    x1_hat = (x0[0] - b / a) * np.exp(-a * k) + b / a
    x0_hat = np.r_[x0[0], np.diff(x1_hat)]

    return {
        "a": a,
        "b": b,
        "fitted": x0_hat[:len(x0)],
        "forecast": x0_hat[len(x0):]
    }

x = [20, 23, 27, 31, 36, 42]
result = gm11(x, horizon=3)
print(result)
```

## 4. 级比检验

常见级比：

$$
\lambda(k)=\frac{x^{(0)}(k-1)}{x^{(0)}(k)}
$$

经验可容区间为：

$$
\left(e^{-2/(n+1)},e^{2/(n+1)}\right)
$$

若大量级比不在区间，原序列可能不适合直接建模，可考虑平移变换，但平移也会改变解释，必须报告。

## 5. 验证

- 留出最后 1～数期做真正预测检验；
- 报告 MAE/MAPE 等；
- 检查相对残差；
- 比较朴素增长率或指数趋势基线；
- 说明预测步数为何合理。

仅在原样本上“后验差检验优秀”不能替代样本外验证。

## 6. 论文表达

> 序列为正、样本较少且呈平滑单调增长，级比大部分落入可容区间，故采用 GM(1,1) 作为小样本基线。留出最后两期验证，模型 MAPE 为……。鉴于模型假设未来按近似指数规律发展，仅进行……期短期预测。

## 7. 易错点

- 对周期或负数序列直接使用。
- 只看拟合精度，不留出验证。
- 预测很远并给出过强结论。
- 认为 $|a|<0.5$ 就自动保证未来 3～8 期准确。
