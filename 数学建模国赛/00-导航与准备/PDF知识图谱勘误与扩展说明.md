# PDF 知识图谱勘误与扩展说明

本笔记库以《全国大学生数学建模竞赛 C 题知识图谱》为主线，但不照抄。原文件适合作为入门地图，部分表述为了通俗而过度简化。以下修正会贯彻到各方法笔记。

## 1. 数据处理相关

| 原文件中的简化说法 | 更严谨的理解 |
|---|---|
| 使用测试集训练就是“过拟合” | 更直接的问题是**数据泄漏**和评估偏乐观；过拟合是训练表现好而泛化差的现象 |
| Z-score 把数据变成标准正态分布 | Z-score 只保证样本均值约为 0、标准差约为 1，不会把偏态或多峰分布自动变成正态 |
| IQR 对所有类型数据通用且异常应剔除 | IQR 是稳健的单变量规则，但异常可能是真实且重要的极端事件，应先核查业务意义 |
| MICE 本质就是贝叶斯迭代 | MICE 是逐变量条件模型的多重插补框架；具体算法可采用不同模型与随机机制，不应一概称为贝叶斯 |
| Rubin 规则只适用于线性/逻辑回归 | Rubin 合并规则适用于很多具有估计值与标准误的统计量，不限于这两类回归；具体统计量需检查可合并条件 |
| statsmodels 提供 Little 检验 | statsmodels 提供 MICE，但并不等于直接提供 Little MCAR 检验；Python 可使用专门实现，R 也有相关包 |

## 2. 相关、回归与统计推断

| 原文件中的简化说法 | 更严谨的理解 |
|---|---|
| Pearson 必须要求数据本身正态 | 相关系数的计算不要求变量正态；显著性检验和置信区间的经典推断才依赖更强假设 |
| 数据清洗与低相关就保证自变量独立 | 不相关不等于独立；线性回归更关键的是条件均值、误差独立/弱相关、线性和方差结构等假设 |
| Spearman 看两个变量“变化像不像” | Spearman 衡量秩之间的单调关联；先升后降的非单调关系可能得到接近 0 |
| Logistic 回归必须标准化 | 数学上并非必须；有正则化、量纲差异大或优化困难时通常强烈建议标准化 |
| p 值小就说明影响大 | p 值只反映与原假设的不相容程度，还要报告效应量、置信区间和实际意义 |

## 3. 时间序列

| 原文件中的简化说法 | 更严谨的理解 |
|---|---|
| 通过 ACF/PACF 截尾即可确定 p、q | 截尾规则是初步线索，应结合 AIC/BIC、残差诊断与滚动验证 |
| ARIMA 残差正态就说明是白噪声 | 白噪声核心是零均值、方差稳定和无自相关；应使用残差图与 Ljung-Box 等检验，正态性是另一件事 |
| 不平稳就不断高阶差分 | 过度差分会放大噪声；通常结合图形、领域知识和 ADF/KPSS，尽量使用低阶差分 |
| GM(1,1) 是小样本兜底 | 它只适合近似指数、单调且平滑的非负序列，还应进行级比、残差和后验差等诊断 |

## 4. 优化与机器学习

| 原文件中的简化说法 | 更严谨的理解 |
|---|---|
| 整数规划没有好的求解方法 | 现代求解器使用分支定界、割平面等方法，可对许多中等规模问题给出可证明的最优解或最优间隙 |
| 遗传算法、模拟退火能找到全局最优 | 它们是随机启发式方法，通常只能给出较好解，不保证有限时间内获得全局最优 |
| NSGA-II 适用于所有多目标问题且是首选 | 它是常用方法之一；目标数多、约束复杂或评价昂贵时可能需要其他算法 |
| 决策树现在基本没人用 | 单树仍是重要的可解释基线，也是随机森林和提升树的基础 |
| SVM/K-Means/DBSCAN 有固定样本量范围 | 不存在通用的硬阈值；可行性取决于样本数、维度、稀疏性、噪声、参数和算力 |
| PCA 最后通常留 2～3 维并保留 95% 信息 | 主成分数应按累计解释方差、验证性能和解释需求选择，2～3 维主要是为了可视化 |

## 5. 综合评价与验证

| 原文件中的简化说法 | 更严谨的理解 |
|---|---|
| 客观赋权就是没有主观性 | 指标选择、正向化、标准化和方法选择仍包含主观判断；“客观”只是权重由数据计算 |
| TOPSIS 得分代表绝对优劣 | 贴近度是给定方案集合、指标和权重下的相对结果，加入/删除方案可能改变排序 |
| 扰动参数就是完整敏感性分析 | 单因素扰动是局部方法；模型复杂时可用全局敏感性、Bootstrap 或蒙特卡洛 |
| 换模型且趋势一致就证明稳健 | 还应检查数据抽样、异常处理、参数范围、指标选择和结构假设 |
