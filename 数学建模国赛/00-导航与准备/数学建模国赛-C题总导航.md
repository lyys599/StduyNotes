## 1. C 题到底在考什么

C 题通常以真实数据和管理、经济、社会、生态等背景为载体，核心不是堆模型，而是完成下面的证据链：

```mermaid
flowchart LR
    A["读题与业务理解"] --> B["数据审计与清洗"]
    B --> C["探索性分析"]
    C --> D["提出假设与选择模型"]
    D --> E["训练、求解或评价"]
    E --> F["检验与不确定性分析"]
    F --> G["解释结论与提出建议"]
    G --> H["论文与支撑材料复现"]
```

一篇好的 C 题论文应当回答：

1. 为什么这样处理数据？
2. 为什么这个模型适合这个问题？
3. 参数如何确定，代码能否复现？
4. 结果是否可靠、稳定，误差来自哪里？
5. 结论对题目中的决策者意味着什么？

## 12. 每篇方法笔记的检查标准

完成一篇后，至少能回答：

- 这个方法解决什么问题，不解决什么问题？
- 输入、输出、关键假设是什么？
- 为什么选择它，而不是相邻方法？
- 代码中每个关键步骤在做什么？
- 输出结果如何解释？
- 论文中怎样描述而不夸大？
- 有哪些会导致数据泄漏、过拟合或错误结论的陷阱？
