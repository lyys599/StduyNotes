# 线性规划

## 1. 标准结构

$$
\min_x c^Tx
$$

满足：

$$
A_{ub}x\le b_{ub},\quad A_{eq}x=b_{eq},\quad l\le x\le u
$$

目标和约束都必须是决策变量的线性函数。若原问题要最大化，可最小化负目标；许多建模工具也能直接表达最大化。

## 2. 建模四步

1. 定义决策变量及单位。
2. 写目标函数。
3. 逐条翻译资源、需求、平衡和边界约束。
4. 检查量纲、可行性和解的业务含义。

## 3. 生产计划案例

产品 A、B 单位利润为 3、5；资源约束为：

$$
2x_A+x_B\le 100
$$

$$
x_A+3x_B\le 90,\quad x_A,x_B\ge0
$$

```python
import numpy as np
from scipy.optimize import linprog

# 最大化 3x_A + 5x_B -> 最小化负利润
c = np.array([-3, -5])
A_ub = np.array([
    [2, 1],
    [1, 3]
])
b_ub = np.array([100, 90])

result = linprog(
    c,
    A_ub=A_ub,
    b_ub=b_ub,
    bounds=[(0, None), (0, None)],
    method="highs"
)

print("是否成功:", result.success)
print("最优产量:", result.x)
print("最大利润:", -result.fun)
print("约束松弛:", result.ineqlin.residual)
```

## 4. 结果解释

- `success`：求解器是否找到满足标准的解；
- `x`：决策变量；
- `fun`：最小化目标，记得恢复最大化符号；
- `residual`：资源剩余量；
- 对偶值/影子价格：资源上限增加一个单位时最优目标的边际变化，只在局部和模型假设下解释。

## 5. 敏感性与稳健性

利润、成本、资源常是估计值。至少对关键参数做[[敏感性分析]]：

- 利润 ±10%；
- 容量变化；
- 需求区间；
- 替代约束。

若不确定性很大，可考虑情景规划或鲁棒优化，而不是把点估计当精确事实。

## 6. 论文表达

> 以各产品产量为非负连续决策变量，以总利润最大为目标，并根据两类资源容量建立线性不等式约束。求解得到……。约束 1 的剩余量为 0，说明其为紧约束；敏感性分析显示当单位利润在……范围变化时，最优方案保持不变。

## 7. 易错点

- 人数、车辆等不可分变量却用连续解。
- 漏写非负或容量约束。
- 单位不一致。
- 求解器成功就不检查业务可行性。
- 把估计参数当无误差常数。
