# 整数规划与 0-1 规划

## 1. 核心区别

- 整数规划：部分或全部决策变量只能取整数。
- 0-1 规划：变量表示选择/不选择、开/关、分配/不分配。
- MILP：目标和约束线性，同时含连续与整数变量。

现代求解器使用分支定界、割平面等方法，许多中等规模问题可以得到可证明最优解或最优间隙；“整数规划没有好方法”是不准确的。

## 2. 背包选择案例

三项目价值为 8、6、5，资源消耗为 4、3、2，总容量 6。选择变量 $x_i\in\{0,1\}$。

```python
import numpy as np
from scipy.optimize import milp, LinearConstraint, Bounds

value = np.array([8, 6, 5])
cost = np.array([[4, 3, 2]])

result = milp(
    c=-value,                         # 最大化价值
    integrality=np.ones(3),           # 三个变量为整数
    bounds=Bounds(np.zeros(3), np.ones(3)),
    constraints=LinearConstraint(
        cost,
        lb=-np.inf,
        ub=6
    )
)

print("选择:", np.rint(result.x).astype(int))
print("最大价值:", -result.fun)
```

## 3. 常见逻辑约束

若选 A 必须选 B：

$$
x_A\le x_B
$$

A、B 至多选一个：

$$
x_A+x_B\le1
$$

A、B 恰选一个：

$$
x_A+x_B=1
$$

至少选 $k$ 个：

$$
\sum_i x_i\ge k
$$

## 4. Big-M 要谨慎

用很大的 $M$ 表达逻辑会造成数值不稳定和松弛过弱。应根据业务给出尽可能紧的上界，不要随手写 $10^9$。

## 5. 求解结果

大规模问题可能在时间限制内只得到：

- 当前最好可行解；
- 最佳下/上界；
- optimality gap。

论文应报告求解器、时间、间隙和硬件，而不是只写“最优”。

## 6. 论文表达

> 以 $x_i=1$ 表示选择第 $i$ 个站点，反之为 0。模型在容量、覆盖和互斥约束下最大化总收益。采用 MILP 求解器，最终相对最优间隙为……，所有整数和逻辑约束均满足。

## 7. 易错点

- 连续求解后简单四舍五入，导致约束失效。
- 0/1 变量含义不写清。
- Big-M 过大。
- 忽略不可行状态和求解间隙。
