# 蒙特卡洛模拟

## 1. 核心思想

为不确定输入指定概率分布，反复随机抽样并运行模型，得到输出分布。它回答的不是“唯一结果是多少”，而是：

- 期望、分位数和置信区间；
- 超过阈值的概率；
- 最坏情景；
- 哪些输入驱动风险。

## 2. 利润风险案例

利润：

$$
\Pi=(P-C)Q-F
$$

```python
import numpy as np

rng = np.random.default_rng(42)
n = 100_000

price = rng.normal(100, 8, n)
cost = rng.normal(65, 5, n)
demand = rng.triangular(800, 1000, 1300, n)
fixed = 20_000

profit = (price - cost) * demand - fixed

print("期望利润:", profit.mean())
print("5%分位数:", np.quantile(profit, 0.05))
print("亏损概率:", np.mean(profit < 0))
```

## 3. 分布从哪里来

- 历史数据拟合；
- 专家给出的合理区间；
- 题目上下界；
- 情景假设；
- 参数估计的不确定性。

不能因为方便就默认所有输入独立且正态。价格与需求可能相关，可用相关抽样或联合分布。

## 4. 收敛检查

逐步增加模拟次数，观察均值/分位数是否稳定。罕见事件概率需要远多于普通均值估计的样本数。

```python
for m in [1000, 5000, 20000, 100000]:
    print(m, profit[:m].mean())
```

## 5. 与敏感性分析

蒙特卡洛给输出分布；[[敏感性分析]]说明哪些输入影响最大。可结合秩相关、回归、Sobol 指标等。

## 6. 论文表达

> 根据历史数据为价格与成本拟合分布，并依据题目区间对需求采用三角分布。在考虑价格—需求相关性的条件下进行 100000 次模拟，期望利润为……，亏损概率为……，5% 风险分位数为……。

## 7. 易错点

- 输入分布没有依据。
- 忽略变量相关性。
- 把模拟误差与模型结构不确定性混为一谈。
- 只报告均值，不报告尾部风险。
- 未固定随机种子与版本。
