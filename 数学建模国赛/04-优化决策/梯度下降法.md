# 梯度下降法

## 1. 更新规则

对可微目标函数 $J(\theta)$：

$$
\theta_{t+1}=\theta_t-\eta\nabla J(\theta_t)
$$

$\eta$ 是学习率。梯度指出局部上升最快方向，取负梯度下降。

## 2. 三种形式

- Batch GD：每步使用全部样本，稳定但大数据慢。
- SGD：每步一个样本，噪声大但更新快。
- Mini-batch：折中，是神经网络常用形式。

## 3. 线性回归手写案例

```python
import numpy as np

x = np.array([1., 2., 3., 4.])
y = np.array([3., 5., 7., 9.])

w = 0.0
b = 0.0
lr = 0.05
n = len(x)

for _ in range(1000):
    pred = w * x + b
    error = pred - y
    dw = (2 / n) * np.sum(error * x)
    db = (2 / n) * np.sum(error)
    w -= lr * dw
    b -= lr * db

print(w, b)
```

应得到接近 $y=2x+1$。

## 4. 学习率

- 太大：振荡、发散；
- 太小：收敛慢；
- 可使用衰减、动量、Adam 等变体；
- 特征标准化常显著改善收敛。

## 5. 是否得到全局最优

- 凸目标：合适条件下可收敛到全局最优；
- 非凸目标：通常只保证到驻点或局部区域；
- 梯度为 0 也可能是鞍点。

## 6. 实战定位

竞赛中通常直接调用 sklearn、SciPy 或深度学习框架，不需手写优化器；但理解梯度下降有助于解释 Logistic、神经网络和正则化模型的训练。

## 7. 易错点

- 不标准化导致“狭长谷”收敛很慢。
- 学习率只试一个。
- 目标函数未正确求导。
- 非凸问题宣称全局最优。
- 只看损失下降，不看验证误差。
