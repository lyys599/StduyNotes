# 决策树

## 1. 原理

决策树不断选择“特征 ≤ 阈值”等切分，使子节点更纯：

- 分类：Gini、不纯度或熵；
- 回归：均方误差、绝对误差等。

单棵树仍是重要的可解释基线，并非“已无人使用”；它也是随机森林与提升树的基础。

## 2. Python 分类案例

```python
from sklearn.tree import DecisionTreeClassifier, plot_tree
from sklearn.model_selection import cross_val_score
import matplotlib.pyplot as plt

model = DecisionTreeClassifier(
    max_depth=3,
    min_samples_leaf=5,
    class_weight="balanced",
    random_state=42
)

score = cross_val_score(
    model, X, y, cv=5, scoring="f1"
)
print(score.mean(), score.std())

model.fit(X, y)
plt.figure(figsize=(12, 6))
plot_tree(
    model,
    feature_names=X.columns,
    class_names=["0", "1"],
    filled=True
)
plt.show()
```

树通常不需要标准化，但类别仍需编码，缺失处理取决于具体实现。

## 3. 过拟合控制

- `max_depth`；
- `min_samples_leaf`；
- `min_samples_split`；
- `max_leaf_nodes`；
- `ccp_alpha` 成本复杂度剪枝。

深树训练误差很低，但对数据小变化非常敏感。

## 4. 解释边界

树的路径可转成规则，但：

- 路径是该模型在该数据上的分割，不是自然规律；
- 相邻高度相关特征可能互相替代；
- 重要性有偏；
- 剪枝后的简单树更适合论文展示。

## 5. 论文表达

> 为获得可解释基线，建立最大深度为……的决策树。树深和叶节点最小样本数通过交叉验证选择。主要分裂规则为……，但其含义仅限于预测关联，并通过随机森林与 Logistic 结果验证稳定性。

## 6. 易错点

- 展示一棵巨大到无法阅读的树。
- 用训练准确率选深度。
- 认为树不需要任何预处理。
- 将阈值规则解释为因果边界。
