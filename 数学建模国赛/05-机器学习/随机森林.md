# 随机森林

## 1. 原理

随机森林对训练样本做 Bootstrap 抽样，并在每次节点切分时随机选择部分特征，训练多棵去相关的树：

- 分类：投票/平均概率；
- 回归：平均预测。

平均可降低单树的高方差，常是表格数据的强基线。

## 2. Python 回归案例

```python
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import cross_validate, KFold

model = RandomForestRegressor(
    n_estimators=500,
    max_features="sqrt",
    min_samples_leaf=3,
    random_state=42,
    n_jobs=-1
)

cv = KFold(5, shuffle=True, random_state=42)
scores = cross_validate(
    model,
    X,
    y,
    cv=cv,
    scoring=["r2", "neg_mean_absolute_error"],
    n_jobs=-1
)

print(scores["test_r2"].mean())
print(-scores["test_neg_mean_absolute_error"].mean())
```

树模型不要求标准化，但仍需防止泄漏、正确编码和处理缺失。

## 3. 关键参数

- `n_estimators`：树数，增加后通常更稳定但更慢；
- `max_depth`、`min_samples_leaf`：控制复杂度；
- `max_features`：树之间的随机性；
- `class_weight`：类别不平衡；
- `max_samples`：每棵树的样本比例。

## 4. OOB 与交叉验证

可启用 `oob_score=True` 获得袋外估计，但复杂预处理和分组/时间数据仍应使用合适交叉验证。

## 5. 特征重要性

默认 impurity importance 偏爱高基数和可多次切分的变量。优先补充验证集上的 permutation importance，详见[[模型解释与特征重要性]]。

## 6. 论文表达

> 随机森林用于捕捉变量间非线性与交互，并以线性回归为可解释基线。通过交叉验证选择叶节点最小样本数和特征采样比例。验证 MAE 为……，Permutation importance 显示……，其稳定性通过重复抽样检验。

## 7. 易错点

- 树越多就一定不会过拟合。
- 直接把默认重要性解释为因果。
- 时间序列随机交叉验证。
- 只报告精度，不解释错误样本。

参考：Breiman (2001)；[scikit-learn ensembles](https://scikit-learn.org/stable/modules/ensemble.html#forest)。
