# 模型解释与特征重要性

## 1. 三个层次

- 全局：模型总体依赖哪些特征？
- 方向/形状：特征变化时预测如何变化？
- 局部：为什么某个样本得到这个预测？

任何重要性都是“对该模型预测的贡献”，不是因果影响。

## 2. Permutation importance

在验证集随机打乱某特征，观察性能下降：

```python
import pandas as pd
from sklearn.inspection import permutation_importance

result = permutation_importance(
    fitted_model,
    X_test,
    y_test,
    scoring="neg_mean_absolute_error",
    n_repeats=30,
    random_state=42,
    n_jobs=-1
)

importance = pd.DataFrame({
    "feature": X_test.columns,
    "mean": result.importances_mean,
    "std": result.importances_std
}).sort_values("mean", ascending=False)

print(importance)
```

相关特征会互相替代，打乱其中一个时性能下降可能不大，不能因此断言不重要。

## 3. Partial Dependence

PDP 展示平均预测随特征变化，但默认会组合现实中不存在的特征值；强相关特征下谨慎。

```python
from sklearn.inspection import PartialDependenceDisplay

PartialDependenceDisplay.from_estimator(
    fitted_model,
    X_test,
    features=["收入", "年龄"]
)
```

ICE 展示各样本曲线，可发现异质性。

## 4. SHAP

SHAP 可提供全局和局部贡献解释，尤其适合树模型。它解释的是相对基准预测的分摊，不等于真实机制。安装和接口随版本变化，比赛前锁定版本并保存环境。

## 5. 稳定性

重要性应在不同折、Bootstrap 或随机种子下重复。报告均值和波动，而不是单次排行榜。

## 6. 论文表达

> 在封存验证数据上计算 30 次置换重要性。特征 A 的平均性能下降最大，且在各折中方向稳定。PDP 显示预测随 A 增加呈……关系；该结果反映模型关联，不能单独解释为因果效应。

## 7. 易错点

- 用训练集计算重要性并过度乐观。
- 将 impurity/gain importance 当唯一证据。
- 相关特征下逐个解释。
- 用 SHAP 图代替业务分析。
- 局部解释推广到所有样本。
