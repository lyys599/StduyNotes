# 超参数搜索与模型选择

## 1. 参数与超参数

- 参数：从数据中学习，如回归系数、树的分裂。
- 超参数：训练前设定，如树深、正则强度、SVM 的 $C$。

调参的目标不是使训练分数最高，而是获得稳定泛化与合理复杂度。

## 2. RandomizedSearchCV 案例

```python
from scipy.stats import randint, loguniform
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import RandomizedSearchCV, KFold

cv = KFold(5, shuffle=True, random_state=42)

search = RandomizedSearchCV(
    RandomForestRegressor(random_state=42, n_jobs=-1),
    param_distributions={
        "n_estimators": randint(200, 800),
        "max_depth": [None, 3, 5, 8, 12],
        "min_samples_leaf": randint(1, 15),
        "max_features": [0.5, "sqrt", 1.0]
    },
    n_iter=40,
    scoring="neg_mean_absolute_error",
    cv=cv,
    random_state=42,
    n_jobs=-1,
    return_train_score=True
)

search.fit(X_train, y_train)
print(search.best_params_)
print(-search.best_score_)
```

连续尺度参数如正则强度适合 `loguniform`。

## 3. 搜索顺序

1. 设简单基线。
2. 根据算法原理选择 2～4 个高影响参数。
3. 先粗范围随机搜索。
4. 在优秀区域小范围细化。
5. 查看训练—验证差距与参数稳定性。
6. 最终在封存测试集评估。

## 4. 嵌套交叉验证

当需要公平比较“经过调参的多个算法”：

- 内层：调参；
- 外层：估计调参流程的泛化性能。

否则直接报告最佳交叉验证分数会有选择偏差。

## 5. 一标准误规则

若多个模型分数接近，可选择性能在最佳值一个标准误范围内最简单的模型，而不是追逐很小的均值优势。

## 6. 论文表达

> 对每种算法先依据原理设定有限搜索空间，采用随机搜索减少无效组合。内层五折选择超参数，外层五折估计泛化性能。若性能差异不超过一个标准误，优先选择更简单、可解释和运行更快的模型。

## 7. 易错点

- 搜索空间没有理论依据。
- 用测试集挑参数。
- 比较一个精调模型和一个默认模型。
- 报告最佳单折分数。
- 调参预算巨大但样本很小。
