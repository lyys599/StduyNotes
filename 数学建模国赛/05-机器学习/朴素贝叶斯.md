# 朴素贝叶斯

## 1. 原理

贝叶斯公式：

$$
P(y|x)\propto P(y)P(x|y)
$$

朴素假设：给定类别 $y$ 后，各特征条件独立：

$$
P(x|y)=\prod_j P(x_j|y)
$$

现实中常不完全成立，但模型仍可能成为快速、稳定的分类基线。

## 2. 变体

| 模型 | 特征类型 |
|---|---|
| GaussianNB | 连续特征近似高斯 |
| MultinomialNB | 计数/词频、非负 |
| BernoulliNB | 二元出现/不出现 |
| CategoricalNB | 离散类别 |

## 3. GaussianNB 案例

```python
from sklearn.naive_bayes import GaussianNB
from sklearn.model_selection import cross_validate, StratifiedKFold

model = GaussianNB()
cv = StratifiedKFold(5, shuffle=True, random_state=42)

scores = cross_validate(
    model,
    X,
    y,
    cv=cv,
    scoring=["accuracy", "f1", "roc_auc"]
)
print(scores["test_f1"].mean())
```

朴素贝叶斯通常不依赖距离，因此不必为了算法本身标准化；但变换可能影响 Gaussian 假设，应以验证为准。

## 4. 优缺点

优点：

- 训练和预测快；
- 小数据可作为基线；
- 概率结构直观；
- 文本稀疏特征很常用。

缺点：

- 条件独立假设较强；
- 相关特征会重复计入证据；
- 概率常不够校准；
- 连续变量分布假设可能不匹配。

不存在统一“5000 以下才适合”的样本阈值。

## 5. 论文表达

> 采用 Gaussian Naive Bayes 作为低复杂度概率分类基线。尽管特征条件独立假设较强，但其训练快、参数少，可用于判断复杂模型是否带来稳定增益。模型概率另行检查校准。

## 6. 易错点

- 对负数特征使用 MultinomialNB。
- 高度相关特征全部放入并过度解释概率。
- 默认输出概率即为准确风险概率。
- 依据固定样本量表格机械选模型。
