# 描述统计与分布诊断

## 1. 四类描述量

| 维度 | 常用指标 | 解释 |
|---|---|---|
| 中心 | 均值、中位数、众数 | 典型水平 |
| 离散 | 标准差、IQR、极差、变异系数 | 波动程度 |
| 形状 | 偏度、峰度、直方图、ECDF | 对称、长尾、多峰 |
| 位置 | 分位数 | 不依赖正态假设的位置描述 |

变异系数 $CV=s/\bar x$ 只适合有真实零点且均值不接近 0 的正值变量。

## 2. Python 案例

```python
import numpy as np
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
from scipy import stats

rng = np.random.default_rng(42)
x = rng.lognormal(mean=2, sigma=0.6, size=200)

summary = pd.Series(x).describe(
    percentiles=[0.05, 0.25, 0.5, 0.75, 0.95]
)
print(summary)
print("偏度:", stats.skew(x, bias=False))
print("超额峰度:", stats.kurtosis(x, fisher=True, bias=False))

fig, axes = plt.subplots(1, 2, figsize=(10, 4))
sns.histplot(x=x, kde=True, ax=axes[0])
stats.probplot(x, dist="norm", plot=axes[1])
fig.tight_layout()
plt.show()
```

## 3. 正态性不要只看 p 值

- Q-Q 图：中间和尾部偏离在哪里；
- 直方图/核密度：偏态、多峰；
- Shapiro-Wilk：小到中等样本常用；
- 大样本中检验对微小偏离很敏感。

```python
stat, p = stats.shapiro(x)
print(stat, p)
```

应结合模型用途。线性回归通常关注的是**误差/残差条件分布**，不是每个自变量必须正态。

## 4. 变换

- 正值右偏：`np.log1p(x)`；
- 含 0 或负数：Yeo-Johnson；
- Box-Cox 要求严格正值。

变换后系数解释会变化，应说明是否需要逆变换及偏差修正。

## 5. 论文表达

> 指标均值明显高于中位数，偏度为……，直方图与 Q-Q 图显示右偏和重尾。考虑到极端值具有实际意义，本文不直接剔除，而采用 MAE 与稳健性分析，并比较原尺度和对数尺度模型。

## 6. 易错点

- 把“p<0.05 不正态”当作不能使用任何参数方法。
- 只报告均值，不报告离散和样本量。
- KDE 平滑参数导致虚假峰。
- 忽略分组后分布与总体分布的差异。
