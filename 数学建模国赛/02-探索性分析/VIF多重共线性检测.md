# VIF 多重共线性检测

## 1. 定义

把第 $j$ 个自变量用其余自变量回归，得到 $R_j^2$：

$$
VIF_j=\frac{1}{1-R_j^2}
$$

VIF 表示由于自变量间线性关联，系数方差被膨胀的程度。它主要影响**系数稳定和推断**，不一定显著降低预测性能。

## 2. 经验阈值不是硬法律

- 接近 1：共线性弱；
- 大于 5：值得检查；
- 大于 10：常被认为严重。

阈值应结合样本量、研究目标和系数稳定性。哑变量组与交互项会自然产生较高 VIF，要结合模型结构解释。

## 3. Python 案例

```python
import pandas as pd
import statsmodels.api as sm
from statsmodels.stats.outliers_influence import variance_inflation_factor

X = df[["盐", "酱油", "油"]].dropna()
X = sm.add_constant(X)

vif = pd.DataFrame({
    "变量": X.columns,
    "VIF": [
        variance_inflation_factor(X.values, i)
        for i in range(X.shape[1])
    ]
})
print(vif)
```

截距的 VIF 通常不作为解释重点。

## 4. 处理策略

1. 核对是否有重复或线性派生变量，如总量与各部分同时进入。
2. 依据业务保留更可解释或质量更高的变量。
3. 合成指标或使用 [[PCA主成分分析]]。
4. 使用 [[岭回归]] 稳定系数。
5. 使用 [[Lasso回归]] 做稀疏选择，但相关变量中选择可能不稳定。
6. 若目标是纯预测，可用交叉验证判断是否真的需要处理。

## 5. 论文表达

> 相关热图提示若干变量间存在较强线性关系，进一步计算 VIF。变量 A、B 的 VIF 分别为……。为减少系数不稳定，本文结合业务含义删除重复定义变量，并采用岭回归作为对照。处理后最大 VIF 为……。

## 6. 易错点

- 用成对相关低就断言没有多重共线性。
- VIF 高就按数值从大到小机械删除。
- 在树模型上花大量篇幅处理 VIF。
- 对类别变量全部哑编码且保留所有类别与截距，造成完全共线。
- 把不相关当作统计独立。
