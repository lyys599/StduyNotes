# 建模可视化选择指南

## 1. 按问题选图

| 想回答的问题 | 推荐图 | 避免 |
|---|---|---|
| 单变量分布 | 直方图、ECDF、箱线/小提琴 | 3D 饼图 |
| 两连续变量关系 | 散点图、回归线、hexbin | 只报相关系数 |
| 类别间数值差异 | 箱线图、点图、置信区间图 | 只画均值柱状图 |
| 时间变化 | 折线图、季节子图 | 无序连接点 |
| 多变量相关 | 热图、散点矩阵 | 变量过多的彩色矩阵 |
| 方案比较 | 点图、排序条形图 | 雷达图堆太多方案 |
| 参数敏感性 | 龙卷风图、响应曲线 | 只列一串系数 |
| 多目标优化 | Pareto 散点图 | 把所有目标强行合成一分 |

## 2. 最小绘图规范

```python
import matplotlib.pyplot as plt
import seaborn as sns

sns.set_theme(style="whitegrid")
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei"]
plt.rcParams["axes.unicode_minus"] = False

fig, ax = plt.subplots(figsize=(7, 4))
sns.scatterplot(
    data=df,
    x="投入",
    y="产出",
    hue="地区",
    ax=ax
)
ax.set(
    title="投入与产出的关系",
    xlabel="投入（万元）",
    ylabel="产出（万元）"
)
fig.tight_layout()
fig.savefig("投入与产出.png", dpi=300, bbox_inches="tight")
plt.show()
```

## 3. 图表必须包含的证据

- 标题说明问题；
- 坐标轴名称和单位；
- 图例能读懂；
- 样本量或误差条含义；
- 颜色对色盲友好；
- 不截断会误导的坐标轴；
- 图注说明数据处理。

## 4. 热图注意

```python
corr = df.select_dtypes("number").corr(method="pearson")
sns.heatmap(
    corr,
    vmin=-1,
    vmax=1,
    center=0,
    cmap="vlag",
    annot=True,
    fmt=".2f"
)
```

主对角线为 1，因为变量与自身完全相关。热图只描述成对关系，不能证明因果，也不能完整诊断共线性。

## 5. 论文图与探索图不同

探索时可快速画很多图；论文只保留能支持关键选择或结论的图。同一信息不要同时用表和图重复。

## 6. 易错点

- 双 Y 轴制造虚假同步。
- 柱状图从非零起点夸大差异。
- 平滑线不说明方法和置信区间。
- 分类颜色过多。
- 用截图代替可复现代码输出。
