# 数据筛选与逻辑校验

## 1. 筛选的本质

筛选是依据题意和数据质量规则确定分析总体，不是为了让结果更漂亮。每一条排除规则都应能回答：

- 规则来自题目、业务常识还是统计判断？
- 排除了多少样本？
- 排除后总体是否发生系统性变化？

## 2. 布尔索引最小案例

```python
import pandas as pd

df = pd.DataFrame({
    "年龄": [18, 25, 200, 40],
    "收入": [3000, 8000, 5000, -100],
    "状态": ["有效", "有效", "有效", "作废"]
})

mask = (
    df["年龄"].between(0, 120)
    & (df["收入"] >= 0)
    & df["状态"].eq("有效")
)

clean = df.loc[mask].copy()
excluded = df.loc[~mask].copy()
```

括号不可省略，因为 `&`、`|` 与比较运算的优先级容易导致错误。多个条件使用 `&` 和 `|`，不要使用 Python 的 `and`、`or`。

## 3. 给错误原因留痕

```python
flags = pd.DataFrame(index=df.index)
flags["年龄越界"] = ~df["年龄"].between(0, 120)
flags["收入为负"] = df["收入"] < 0
flags["记录作废"] = df["状态"].ne("有效")

df["排除原因"] = flags.apply(
    lambda row: "；".join(row.index[row]),
    axis=1
)
```

这样可以统计每类规则影响多少样本：

```python
print(flags.sum().sort_values(ascending=False))
```

## 4. 列筛选

可以考虑移除：

- 纯编号、姓名等不应进入模型的标识列；
- 全部相同的列；
- 题后产生、含未来信息的泄漏列；
- 缺失极高且无法可靠恢复的列；
- 与研究目标无关或含义不清的列。

不能仅凭相关系数低就删除特征；非线性模型可能仍能使用它。

## 5. 筛选前后比较

```python
summary = pd.DataFrame({
    "筛选前": df["收入"].describe(),
    "筛选后": clean["收入"].describe()
})
print(summary)
```

如果某个群体被大量排除，应按群体计算排除率，检查选择偏差。

## 6. 论文表达

> 根据题目给出的有效范围与字段逻辑建立规则化校验表。对违反规则的记录先回查原始数据；无法确认或确属录入错误的样本予以排除，并报告各规则对应的排除数量。筛选前后主要变量分布未出现结构性改变。

## 7. 易错点

- 把真实极端值当成录入错误。
- 用目标变量结果倒推删除“不好看”的样本。
- 筛选后忘记重置索引不是严重问题，但用旧行号和外部表匹配会出错。
- 对训练集和测试集使用基于全体数据学出的筛选阈值，造成泄漏。
