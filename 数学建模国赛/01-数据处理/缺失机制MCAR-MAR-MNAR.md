# 缺失机制：MCAR、MAR、MNAR

## 1. 为什么机制比缺失率更重要

设 $R=1$ 表示某值被观察，$R=0$ 表示缺失。缺失机制描述 $R$ 与数据之间的依赖关系，而不是缺失值长什么样。

| 机制 | 缺失概率依赖什么 | 例子 | 可否仅靠观测数据证实 |
|---|---|---|---|
| MCAR 完全随机缺失 | 与已观测和未观测值都无关 | 随机设备故障 | 可检验其是否明显违背，但难以“证明” |
| MAR 随机缺失 | 可依赖已观测变量，不依赖缺失值在给定已观测变量后的剩余信息 | 年龄已知，年轻人更少填收入 | 通常作为可操作假设，不能由数据完全证实 |
| MNAR 非随机缺失 | 即使给定已观测变量，仍依赖缺失值本身或未观测因素 | 收入越高越不愿填收入 | 不能仅靠已观测数据与 MAR 区分 |

> [!important]
> MAR 的“随机”不是完全随机，而是“控制已观测信息后可忽略”。MNAR 也不是“完全没法处理”，但需要选择模型、外部信息或敏感性分析。

## 2. 诊断顺序

1. 统计每列缺失数和缺失率。
2. 画缺失矩阵或缺失相关热图。
3. 创建缺失指示变量，与已观测变量比较。
4. 结合数据生成过程判断原因。
5. 使用 [[Little-MCAR检验]] 检查 MCAR 假设。
6. 对 MAR/MNAR 做情景或敏感性分析。

## 3. Python 探索

```python
import pandas as pd
from scipy.stats import chi2_contingency

df = pd.DataFrame({
    "年龄组": ["青年", "青年", "中年", "中年", "老年", "老年"],
    "收入": [5000, None, 8000, 9000, 6000, 6500]
})

df["收入缺失"] = df["收入"].isna()
table = pd.crosstab(df["年龄组"], df["收入缺失"])
print(table)

if table.shape[1] == 2:
    chi2, p, dof, expected = chi2_contingency(table)
    print("p值:", p)
```

若缺失与年龄组显著相关，MCAR 变得不可信，但这并不能区分 MAR 与 MNAR。

## 4. 不同机制的处理思路

- MCAR 且缺失很少：完整案例分析或简单插补可能影响较小。
- MAR：优先 [[MICE多重插补]]，把与缺失和目标相关的已观测变量纳入插补模型。
- MNAR：建立不同偏移量/选择模型情景，比较结论是否改变，并在局限性中明确。

## 5. 论文表达

严谨写法不是“检验得出数据一定为 MAR”，而是：

> 缺失模式与已观测的年龄、地区存在关联，因此完全随机缺失假设缺乏支持。考虑到无法仅由观测数据区分 MAR 与 MNAR，主分析在 MAR 假设下采用 MICE；随后对缺失值施加不同方向的偏移进行敏感性分析，以评估潜在 MNAR 对结论的影响。

## 6. 易错点

- 根据缺失集中在某群体就直接声称 MNAR。
- 只按缺失率选择算法，不考虑变量类型和机制。
- 插补时遗漏目标变量或重要辅助变量。
- 把插补后的值当作真实观测值，忽略插补不确定性。
