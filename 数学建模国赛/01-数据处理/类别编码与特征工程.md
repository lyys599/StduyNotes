# 类别编码与特征工程

## 1. 核心原则

特征工程把业务含义转换为模型可用的信息。它必须在划分数据后按训练集规则完成，不能根据测试结果反向设计。

## 2. 类别变量编码

- 无序类别：独热编码 One-Hot。
- 真正有等级的类别：有序编码，如“低 < 中 < 高”。
- 高基数类别：合并稀有类、频数编码或交叉验证内目标编码。
- 编号、姓名：通常不应直接作为数值特征。

```python
from sklearn.preprocessing import OneHotEncoder

encoder = OneHotEncoder(
    handle_unknown="ignore",
    sparse_output=False
)
```

`handle_unknown="ignore"` 防止测试集出现新类别时报错。

## 3. 常见特征构造

### 比率与密度

```python
df["人均GDP"] = df["GDP"] / df["人口"].replace(0, float("nan"))
df["负荷率"] = df["实际负荷"] / df["额定容量"]
```

比率的分母不能为 0，且必须有业务意义。

### 时间特征

```python
df["月份"] = df["日期"].dt.month
df["星期"] = df["日期"].dt.dayofweek
df["是否周末"] = df["星期"].isin([5, 6]).astype(int)
```

周期特征可用正余弦避免 12 月与 1 月被认为距离很远：

```python
import numpy as np

df["month_sin"] = np.sin(2 * np.pi * df["月份"] / 12)
df["month_cos"] = np.cos(2 * np.pi * df["月份"] / 12)
```

### 滞后与滚动

```python
df = df.sort_values(["对象", "日期"])
df["lag1"] = df.groupby("对象")["指标"].shift(1)
df["rolling3"] = (
    df.groupby("对象")["指标"]
      .transform(lambda s: s.shift(1).rolling(3).mean())
)
```

先 `shift(1)` 是为了只使用过去信息。

## 4. ColumnTransformer 案例

```python
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline

num_cols = ["年龄", "收入"]
cat_cols = ["地区", "职业"]

num_pipe = Pipeline([
    ("impute", SimpleImputer(strategy="median")),
    ("scale", StandardScaler())
])

cat_pipe = Pipeline([
    ("impute", SimpleImputer(strategy="most_frequent")),
    ("onehot", OneHotEncoder(handle_unknown="ignore"))
])

preprocess = ColumnTransformer([
    ("num", num_pipe, num_cols),
    ("cat", cat_pipe, cat_cols)
])
```

## 5. 特征选择

选择依据可包括：

- 业务合理性；
- 缺失与质量；
- 共线性与冗余；
- 交叉验证增益；
- 稳定的特征重要性；
- 消融实验。

不要只用全数据相关系数筛选后再交叉验证。

## 6. 论文表达

> 根据变量含义构造人均指标、负荷率和仅依赖历史信息的滞后特征。无序类别采用独热编码，连续变量在训练折内完成插补与标准化。所有特征工程封装于 Pipeline，确保验证和测试数据不参与规则学习。

## 7. 易错点

- 将类别编码 1/2/3 后让模型误以为间距相等。
- 计算滚动均值时包含当前或未来目标。
- 使用全数据的类别频率、均值或目标均值。
- 构造大量特征但不做消融和正则化。
