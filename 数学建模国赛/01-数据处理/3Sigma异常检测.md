# 3Sigma 异常检测

## 1. 原理

若数据近似来自正态分布 $N(\mu,\sigma^2)$，则约 99.73% 的观测落在：

$$
[\mu-3\sigma,\ \mu+3\sigma]
$$

样本中通常用 $\bar x$ 和样本标准差 $s$ 估计。超出范围的点是“待核查异常候选”，不是必须删除的错误。

## 2. 适用条件

- 连续变量；
- 分布近似单峰、对称、无严重偏态；
- 样本量足以稳定估计均值和标准差；
- 极端偏离在业务上可被视为异常。

偏态收入、长尾流量、计数数据通常不适合直接使用。

## 3. 最小可运行案例

```python
import numpy as np
import pandas as pd

x = pd.Series([10, 11, 9, 10, 12, 11, 10, 9, 50], name="测量值")

mean = x.mean()
std = x.std(ddof=1)
lower = mean - 3 * std
upper = mean + 3 * std

flag = ~x.between(lower, upper)
result = pd.DataFrame({"x": x, "is_outlier": flag})
print(result)
print("边界:", lower, upper)
```

在很小样本中，极端值会同时拉高均值与标准差，可能反而检测不到自己。这也是 [[稳健异常检测-MAD与IsolationForest]] 更稳健的原因。

## 4. 分组检测

不同设备或地区基线不同，应在可比较群体内计算：

```python
df["z"] = df.groupby("设备")["读数"].transform(
    lambda s: (s - s.mean()) / s.std(ddof=1)
)
df["异常候选"] = df["z"].abs() > 3
```

组内样本过少时不要使用。

## 5. 处理异常候选

1. 回查原始附件和单位；
2. 判断是否录入错误、测量故障或真实极端事件；
3. 可选择修正、保留、截尾、变换、使用稳健模型或删除；
4. 比较处理前后核心结论，作为[[稳健性检验]]。

## 6. 论文表达

> 对近似对称且单峰的测量变量采用 3Sigma 规则标记异常候选。所有候选点均回查原始记录；无法确认的真实极端事件予以保留，并使用稳健模型验证结论。对确认属于单位或录入错误的记录进行修正。

## 7. 易错点

- 未看分布就使用 3Sigma。
- 循环删除异常值直到“没有异常”，导致人为收窄分布。
- 用全体数据确定阈值后评估测试集。
- 把业务极端事件当作噪声删除。

练习：把案例的 50 改为 25、100，观察均值、标准差和判定边界如何变化。
