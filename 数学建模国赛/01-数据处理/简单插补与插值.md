# 简单插补与插值

## 1. 先区分插补与插值

- **插补**：利用统计分布或其他变量估计缺失值，常用于截面表格。
- **插值**：利用有序位置，尤其时间或空间邻近关系估计中间缺口。

时间序列不能因为只有一个变量就机械使用三次样条；缺口长度、边界、趋势和物理约束都要考虑。

## 2. 常见方法

| 方法 | 适合 | 主要风险 |
|---|---|---|
| 均值 | 对称、缺失少的连续变量 | 压低方差、受极端值影响 |
| 中位数 | 偏态连续变量 | 仍会压低方差 |
| 众数 | 类别变量 | 放大多数类别 |
| 常量/“未知” | 缺失本身有信息的类别 | 可能人为造出新类别 |
| 线性插值 | 平滑、短缺口的有序序列 | 无法表达曲率 |
| 样条插值 | 足够平滑且点数充足 | 可能过冲，不宜外推 |

## 3. scikit-learn 简单插补

```python
import pandas as pd
from sklearn.impute import SimpleImputer

df = pd.DataFrame({
    "年龄": [20, 30, None, 50],
    "收入": [3000, None, 7000, 10000]
})

imputer = SimpleImputer(strategy="median", add_indicator=True)
filled = imputer.fit_transform(df)

print(filled)
```

`add_indicator=True` 额外保留“该位置原来是否缺失”，当缺失本身含信息时很有用。正式建模应将插补器放入[[防止数据泄漏与Pipeline]]。

## 4. 类别插补

```python
cat_imputer = SimpleImputer(
    strategy="most_frequent",
    add_indicator=True
)
```

若“未填写”本身可能有意义，也可 `strategy="constant", fill_value="未知"`。

## 5. 时间插值

```python
import pandas as pd

s = pd.Series(
    [10.0, None, 14.0, None, 18.0],
    index=pd.date_range("2026-01-01", periods=5, freq="D")
)

linear = s.interpolate(method="time", limit=1)
print(linear)
```

`limit=1` 限制连续填补长度，防止跨越长缺口强行插值。测试集未来值不能参与训练时点之前的插值。

## 6. 如何验证插补方法

在原本完整的数据中人工遮挡一部分值，然后比较恢复误差：

1. 从非缺失位置随机或按真实缺失模式遮挡。
2. 只用其余值拟合插补器。
3. 比较插补值和真实值的 MAE/RMSE。
4. 检查插补前后的分布、相关性和模型结论。

## 7. 论文表达

> 连续变量呈明显右偏，故采用训练集上的中位数进行插补，并保留缺失指示变量。类别变量以“未知”作为独立类别。对于时间序列中的单点缺口，采用仅使用相邻已知时刻的时间线性插值；连续缺失超过 1 期的片段不作自动插值，单独进行敏感性分析。

## 8. 易错点

- 在划分数据之前用全数据计算均值/中位数。
- 对目标变量随意插补后当作真实标签训练。
- 用未来时间点填补过去，造成未来信息泄漏。
- 只比较“填得像不像”，不检查下游模型结论。
