# 熵权法

## 1. 直觉

一个指标在方案间差异越大，提供的区分信息越多，权重越高。它反映“数据区分度”，不等于业务重要性。

## 2. 公式

对已正向化且非负的矩阵 $Z=(z_{ij})$：

$$
p_{ij}=\frac{z_{ij}}{\sum_i z_{ij}}
$$

$$
e_j=-\frac{1}{\ln n}\sum_i p_{ij}\ln p_{ij}
$$

约定 $0\ln0=0$。差异系数：

$$
d_j=1-e_j
$$

权重：

$$
w_j=\frac{d_j}{\sum_j d_j}
$$

## 3. Python

```python
import numpy as np
import pandas as pd

def entropy_weights(Z: pd.DataFrame) -> pd.Series:
    X = Z.to_numpy(dtype=float)
    if np.any(X < 0):
        raise ValueError("熵权法输入应先转为非负矩阵")

    col_sum = X.sum(axis=0)
    if np.any(col_sum == 0):
        raise ValueError("存在列和为0的指标")

    P = X / col_sum
    logP = np.zeros_like(P)
    mask = P > 0
    logP[mask] = np.log(P[mask])

    n = X.shape[0]
    e = -(P * logP).sum(axis=0) / np.log(n)
    d = 1 - e

    if np.isclose(d.sum(), 0):
        raise ValueError("所有指标均无区分度")

    return pd.Series(d / d.sum(), index=Z.columns)

print(entropy_weights(Z))
```

## 4. 极端值问题

极端值会放大差异并获得高权重。应先核查异常、比较稳健规范化或 Winsorize 情景，并报告排序变化。

## 5. 论文表达

> 对指标完成正向化与无量纲化后采用熵权法。权重反映样本中的区分信息，而非指标的规范性重要程度。为检验极端值影响，进一步采用 CRITIC/截尾数据重算权重，核心排序保持……。

## 6. 易错点

- 原始含负值矩阵直接代入。
- 把熵权叫“完全没有主观性”。
- $p=0$ 时直接计算 `log(0)`。
- 常数列导致权重计算异常。
- 将熵权与 TOPSIS 混成一个方法。
