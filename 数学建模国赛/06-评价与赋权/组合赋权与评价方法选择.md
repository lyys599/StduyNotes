# 组合赋权与评价方法选择

## 1. 为什么组合

- AHP 表达政策/专家偏好；
- 熵权表达指标离散度；
- CRITIC 表达变异与信息冲突。

若题目既重视业务重要性又重视数据差异，可组合：

$$
w=\alpha w^{sub}+(1-\alpha)w^{obj}
$$

$\alpha$ 不能为了得到想要的排序而挑，应来自决策偏好、验证或敏感性分析。

## 2. Python

```python
import pandas as pd

w_ahp = pd.Series(
    {"经济": 0.5, "环境": 0.3, "社会": 0.2}
)
w_entropy = pd.Series(
    {"经济": 0.3, "环境": 0.4, "社会": 0.3}
)

alpha = 0.5
w = alpha * w_ahp + (1 - alpha) * w_entropy
w = w / w.sum()
print(w)
```

## 3. 选择框架

| 问题条件 | 建议 |
|---|---|
| 权威偏好明确 | AHP |
| 只想利用样本差异 | 熵权 |
| 指标冗余明显 | CRITIC |
| 需要方案相对排序 | 权重 + TOPSIS |
| 评价边界模糊 | 模糊综合评价 |
| 主客观都重要 | 组合赋权 |

## 4. 稳健性比“哪个最好”更重要

重算：

- AHP、熵权、CRITIC 三套权重；
- Min-Max 与向量规范化；
- 权重 ±10%；
- 删除一个高相关指标；
- 增删方案。

用 [[Spearman秩相关系数]] 比较排序，并报告头部方案是否稳定。

## 5. 论文表达

> 为兼顾专家偏好与样本区分度，采用 AHP—CRITIC 线性组合权重。组合系数以 0.5 为基准，并在 0.3～0.7 范围内扰动。主要方案在全部情景中均位于前……，说明结论对赋权方式较稳健。

## 6. 易错点

- 组合两个方法只是为了显得复杂。
- 同一数据证据被重复计权。
- 组合系数无依据。
- 只报告最终权重，不报告各来源权重。
- 排名稳定却分数差异极小，仍夸大优劣。
