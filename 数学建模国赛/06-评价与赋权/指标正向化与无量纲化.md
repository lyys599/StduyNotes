# 指标正向化与无量纲化

## 1. 四个环节不要混

1. 指标选择：评价哪些维度。
2. 正向化：统一为“越大越好”。
3. 无量纲化：消除单位和尺度。
4. 赋权与综合：计算权重并排序。

顺序通常是先正向化，再无量纲化。

## 2. 指标类型

### 效益型

越大越好，保持方向。

### 成本型

越小越好，可用：

$$
x'_{ij}=x^{\max}_j-x_{ij}
$$

或在全为正时取倒数，但倒数会改变距离结构。

### 目标型

接近目标 $a$ 最好：

$$
x'_{ij}=1-\frac{|x_{ij}-a|}
{\max_i|x_{ij}-a|}
$$

### 区间型

落在 $[a,b]$ 最好，区间内记为 1，区间外随距离递减。具体函数要符合业务。

## 3. Min-Max 无量纲化

效益型：

$$
z_{ij}=\frac{x_{ij}-\min_i x_{ij}}
{\max_i x_{ij}-\min_i x_{ij}}
$$

成本型：

$$
z_{ij}=\frac{\max_i x_{ij}-x_{ij}}
{\max_i x_{ij}-\min_i x_{ij}}
$$

## 4. Python

```python
import pandas as pd

def minmax_positive(s, kind="benefit"):
    span = s.max() - s.min()
    if span == 0:
        return pd.Series(0.0, index=s.index)
    if kind == "benefit":
        return (s - s.min()) / span
    if kind == "cost":
        return (s.max() - s) / span
    raise ValueError("kind必须是benefit或cost")

Z = pd.DataFrame({
    "收益": minmax_positive(df["收益"], "benefit"),
    "成本": minmax_positive(df["成本"], "cost")
})
```

常数指标不能区分方案，通常应删除或赋零差异权重，并在论文说明。

## 5. 向量规范化

TOPSIS 常用：

$$
z_{ij}=\frac{x_{ij}}
{\sqrt{\sum_i x_{ij}^2}}
$$

它与 Z-score、Min-Max 不同。不同规范化会改变距离和排序，应做稳健性比较。

## 6. 论文表达

> 将收益类指标保留为正向，成本类指标反向转换，目标型指标按距目标值的偏差正向化。随后采用……规范化消除量纲。对零方差指标予以删除，因为其无法区分方案。

## 7. 易错点

- 成本型忘记反向。
- 同一指标重复正向化。
- 公式分母为 0。
- 先看到排序再挑规范化方法。
- “客观赋权”前的指标选择仍带主观性。
