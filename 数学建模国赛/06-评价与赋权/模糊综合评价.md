# 模糊综合评价

## 1. 适用场景

评价边界模糊、结果常用等级表达，例如：

- 满意/较满意/一般/不满意；
- 风险低/中/高；
- 质量优/良/中/差。

若指标都可直接量化排序，TOPSIS 往往更简单。

## 2. 基本元素

- 因素集 $U=\{u_1,\ldots,u_m\}$；
- 评价集 $V=\{v_1,\ldots,v_n\}$；
- 权重向量 $A=(a_1,\ldots,a_m)$；
- 隶属度矩阵 $R=(r_{ij})$，每行通常和为 1。

加权平均型合成：

$$
B=AR
$$

$B$ 表示对象对各评价等级的综合隶属度。

## 3. Python 案例

```python
import numpy as np

# 三个指标的权重
A = np.array([0.4, 0.35, 0.25])

# 对“优、良、中、差”的隶属度
R = np.array([
    [0.6, 0.3, 0.1, 0.0],
    [0.3, 0.5, 0.2, 0.0],
    [0.2, 0.4, 0.3, 0.1]
])

assert np.allclose(R.sum(axis=1), 1)
B = A @ R
print("综合隶属度:", B)

grade_score = np.array([100, 80, 60, 40])
print("加权得分:", B @ grade_score)
```

## 4. 隶属函数

可用三角形、梯形、高斯或基于问卷频率的隶属度。函数形状和阈值是模型假设，必须有领域或数据依据。

## 5. 最大隶属原则的局限

若 $B=[0.35,0.34,0.31,0]$，直接判为“优”会丢失接近关系。应同时报告完整向量、期望得分或置信情景。

## 6. 论文表达

> 将评价等级划分为……，依据……构建隶属函数。指标权重由……获得，采用加权平均算子合成。对象 A 的综合隶属向量为……，其最高隶属等级为……，但与次高等级差仅……，因此结论存在一定模糊性。

## 7. 易错点

- 隶属函数和阈值无依据。
- 权重和隶属度重复表达同一信息。
- 行和不为 1。
- 只报最大等级，不报完整隶属向量。
