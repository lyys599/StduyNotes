# 层次分析法 AHP

## 1. 结构

将问题分为：

- 目标层；
- 准则层；
- 方案层。

专家对同层元素两两比较，形成正互反判断矩阵 $A=(a_{ij})$，满足 $a_{ji}=1/a_{ij}$。

## 2. 权重

常用主特征向量法：

$$
Aw=\lambda_{\max}w
$$

将主特征向量归一化得到权重。

## 3. 一致性检验

$$
CI=\frac{\lambda_{\max}-n}{n-1}
$$

$$
CR=\frac{CI}{RI}
$$

通常 $CR<0.1$ 视为可接受。RI 是同阶随机一致性指标；$n\le2$ 时无需此检验。

## 4. Python 案例

```python
import numpy as np

A = np.array([
    [1,   3,   5],
    [1/3, 1,   2],
    [1/5, 1/2, 1]
], dtype=float)

eigvals, eigvecs = np.linalg.eig(A)
idx = np.argmax(eigvals.real)
lambda_max = eigvals[idx].real
w = np.abs(eigvecs[:, idx].real)
w = w / w.sum()

RI = {1: 0, 2: 0, 3: 0.58, 4: 0.90, 5: 1.12}
n = len(A)
CI = (lambda_max - n) / (n - 1)
CR = 0 if RI[n] == 0 else CI / RI[n]

print("权重:", w)
print("lambda_max:", lambda_max, "CR:", CR)
```

## 5. 判断矩阵来源

- 多名专家独立打分；
- 权威规范；
- 问卷；
- 德尔菲法。

不能由参赛队随意写一个矩阵。合并多名专家时常用几何平均，并报告一致性与分歧。

## 6. 敏感性

改变关键两两比较值或专家权重，观察最终排序。AHP 的主观性不是缺点本身；真正问题是不披露来源和不检查敏感性。

## 7. 论文表达

> 根据……构建目标—准则—方案三层结构。由……名专家独立完成两两比较，采用几何平均合并判断矩阵。准则层一致性比率 $CR=...<0.1$，权重为……。随后对关键判断值进行扰动，排序保持……。

## 8. 易错点

- 判断矩阵不是互反矩阵。
- CR 不通过仍继续使用。
- 指标很多导致比较负担和一致性差。
- 权重来源写成“根据经验”。
- AHP 权重直接用于含量纲原始数据。

参考：Saaty (1980)。
