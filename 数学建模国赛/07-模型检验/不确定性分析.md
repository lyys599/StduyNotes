# 不确定性分析

## 1. 不确定性来源

| 类型 | 例子 | 常见方法 |
|---|---|---|
| 数据噪声 | 测量误差、个体差异 | 预测区间、概率模型 |
| 参数不确定 | 样本有限 | 标准误、Bootstrap |
| 模型不确定 | 不同模型结构 | 模型集合、稳健性 |
| 输入情景 | 成本、需求未来变化 | 蒙特卡洛、情景分析 |
| 缺失机制 | MAR/MNAR | 多重插补、偏移敏感性 |

## 2. 置信区间与预测区间

- 均值置信区间：平均响应的不确定性。
- 个体预测区间：未来单个观测的不确定性，通常更宽。

不要把二者混用。

## 4. 决策不确定性

对每次输入抽样或权重抽样重新求解，统计：

- 每个方案成为第一名的概率；
- 最优决策变量分布；
- 目标值 5%/95% 分位；
- 约束违反概率；
- 后悔值。

比只给一个“最优方案”更诚实。

## 5. 论文表达

> 通过按城市重抽样的 Bootstrap 估计测试 MAE 的 95% 区间，并在需求与成本联合分布下进行蒙特卡洛传播。方案 A 在……% 情景中最优，但在高成本情景下方案 B 风险更低，因此给出条件化建议。

## 6. 易错点

- 只给点估计。
- 普通 Bootstrap 破坏依赖。
- 区间很窄就认为模型无偏。
- 输入分布没有依据。
- 把模型不确定性和随机噪声混为一谈。
