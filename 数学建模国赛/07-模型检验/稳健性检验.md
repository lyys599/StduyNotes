# 稳健性检验

## 1. 稳健的对象

先说清什么应保持：

- 系数方向；
- 关键变量集合；
- 方案排名；
- 预测趋势；
- 政策建议；
- 最优决策结构。

数值完全相同不是必要条件。

## 2. 四类稳健性

### 数据

- Bootstrap/子样本；
- 去除或保留异常值；
- 不同时间窗口；
- 分组留出；
- 缺失处理替代。

### 方法

- 替代模型；
- 不同规范化和权重；
- 不同损失函数；
- 参数范围。

### 指标

- MAE 与 RMSE；
- ROC-AUC 与 PR-AUC；
- 排名相关与头部集合。

### 假设

- MAR/MNAR 情景；
- 需求、成本和约束变化；
- 外生变量预测误差。

## 3. 排名稳健性

```python
from scipy.stats import spearmanr

rank_a = [1, 2, 3, 4, 5]
rank_b = [1, 3, 2, 4, 5]
rho, p = spearmanr(rank_a, rank_b)
print(rho, p)
```

除整体 Spearman 外，还要看第一名/前三名是否变化。

## 4. 稳健不等于挑结果

应事先或透明地列出合理替代方案，完整报告不一致结果，并解释哪些假设驱动差异。

## 5. 论文表达

> 分别使用熵权与 CRITIC、Min-Max 与向量规范化重算方案排序，并对权重进行扰动。各情景的 Spearman 秩相关均高于……，前两名保持不变。异常值处理改变了具体得分但未改变核心建议。

## 6. 易错点

- 只换一个相似模型。
- 看到不一致就不报告。
- 用训练数据重复验证。
- 把“趋势大致相同”当充分证据，却不量化。
- 稳健性分析与敏感性分析概念混乱。
