# 聚类评价指标

## 1. 内部指标

### 轮廓系数

对样本 $i$：

$$
s(i)=\frac{b(i)-a(i)}{\max\{a(i),b(i)\}}
$$

$a(i)$ 为同簇平均距离，$b(i)$ 为最近其他簇平均距离。接近 1 较好，接近 0 表示边界，负值可能分错。

### 其他

- Calinski-Harabasz：簇间离散/簇内离散，越大越好。
- Davies-Bouldin：簇间相似度，越小越好。

## 2. Python

```python
from sklearn.metrics import (
    silhouette_score,
    calinski_harabasz_score,
    davies_bouldin_score
)

print("Silhouette:", silhouette_score(X_scaled, labels))
print("CH:", calinski_harabasz_score(X_scaled, labels))
print("DB:", davies_bouldin_score(X_scaled, labels))
```

指标必须在实际聚类所用的尺度和距离空间中计算。

## 3. 外部指标

若有参考标签，可用 Adjusted Rand Index、NMI。但聚类目标未必与已有标签相同，不能机械追求一致。

## 4. 稳定性

内部指标高不代表簇稳定。应改变：

- 随机种子；
- Bootstrap 样本；
- 特征集合；
- 标准化方法；
- $K$、eps 等参数。

比较簇匹配或 ARI。

## 5. 业务可解释性

检查：

- 每簇样本量是否过小；
- 簇画像是否清晰；
- 分群是否可执行；
- 是否只是某一个尺度很大的变量决定。

## 6. DBSCAN 特殊点

排除噪声后算轮廓系数会提高分数，应同时报告噪声比例；若只有一个簇则轮廓系数无定义。

## 7. 论文表达

> 综合轮廓系数、CH、DB 指标以及业务解释选择……簇。对 50 次重抽样计算 ARI，均值为……，说明聚类结构较稳定/不稳定。DBSCAN 噪声比例为……。

## 8. 易错点

- 只用肘部法。
- 在不同标准化空间比较指标。
- 聚类标签 0/1/2 当成等级。
- 忽略小簇和噪声。
