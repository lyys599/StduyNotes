# 敏感性分析

## 1. 回答什么

- 哪个输入最影响输出？
- 合理扰动会不会改变结论？
- 哪些参数需要更精确测量？

局部敏感系数：

$$
S=\frac{\Delta Y/Y}{\Delta X/X}
$$

它依赖基准点和扰动范围。

## 2. 单因素扰动案例

```python
import pandas as pd

base = {"price": 100, "cost": 65, "demand": 1000}

def profit(p):
    return (p["price"] - p["cost"]) * p["demand"]

rows = []
for name in base:
    for pct in [-0.2, -0.1, 0.1, 0.2]:
        p = base.copy()
        p[name] *= 1 + pct
        rows.append({
            "参数": name,
            "扰动": pct,
            "输出": profit(p),
            "输出变化率": profit(p) / profit(base) - 1,
            "敏感系数": (profit(p) / profit(base) - 1) / pct
        })

result = pd.DataFrame(rows)
print(result)
```

## 3. 龙卷风图

对每个参数记录合理低值与高值对应输出，计算相对基准的区间，按跨度排序。它展示局部情景，不是全局概率风险。

## 4. 局部与全局

- OAT：一次改一个，易解释但忽略交互。
- 情景分析：同时改变相关参数。
- Morris/Sobol：全局敏感性，适合非线性和交互。
- 蒙特卡洛 + 回归/秩相关：实用折中。

参数有相关性时独立扰动可能产生不现实情景。

## 5. 扰动范围

±10%、±20% 只是示例。更好的依据：

- 估计置信区间；
- 历史波动；
- 题目边界；
- 专家范围；
- 政策情景。

## 6. 论文表达

> 根据历史波动为成本、需求分别设置……范围。局部扰动显示输出对需求最敏感；进一步在保持价格—需求相关性的蒙特卡洛情景中验证。尽管目标值变化，最优方案在……范围内不变。

## 7. 易错点

- 所有参数机械 ±10%。
- 只看输出大小，不看结论/排名是否改变。
- 忽略参数交互和相关。
- 将局部敏感性推广到远离基准的范围。
