# 回归评价指标

## 1. 三个核心指标

平均绝对误差：

$$
MAE=\frac1n\sum_i|y_i-\hat y_i|
$$

均方根误差：

$$
RMSE=\sqrt{\frac1n\sum_i(y_i-\hat y_i)^2}
$$

决定系数：

$$
R^2=1-\frac{\sum_i(y_i-\hat y_i)^2}
{\sum_i(y_i-\bar y)^2}
$$

## 2. 解释

- MAE：与目标同单位，对大误差相对稳健。
- RMSE：更惩罚大误差。
- $R^2$：相对均值基线解释的误差改善；测试集上可为负。

不要把 $R^2$ 解释为“预测准确率”或因果解释比例。

## 3. Python

```python
from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error,
    r2_score
)

mae = mean_absolute_error(y_test, pred)
rmse = mean_squared_error(y_test, pred) ** 0.5
r2 = r2_score(y_test, pred)

print({"MAE": mae, "RMSE": rmse, "R2": r2})
```

## 4. MAPE 的陷阱

$$
MAPE=\frac{100\%}{n}\sum_i\left|\frac{y_i-\hat y_i}{y_i}\right|
$$

$y_i=0$ 时无定义，接近 0 时爆炸，对正负目标也不直观。可用 MAE、WAPE、sMAPE 或 MASE，但要结合业务。

## 5. 如何选择

- 错误成本线性：MAE。
- 大错误代价特别高：RMSE。
- 跨数据集比较：需标准化误差或 MASE。
- 时间序列：必须与朴素基线比较。
- 长尾目标：报告分位数误差和分组误差。

## 6. 论文表达

> 以 MAE 为主指标，因为预测误差成本近似与绝对偏差成正比；同时报告 RMSE 以反映大误差。模型测试 MAE 为……，相较均值/朴素基线降低……%。Bootstrap 95% 区间为……。

## 7. 易错点

- 在训练集报告指标。
- 只给一个平均分，不给波动或分组误差。
- 不同目标尺度直接比较 RMSE。
- 测试 $R^2$ 负值却强行解释为“仍较好”。
