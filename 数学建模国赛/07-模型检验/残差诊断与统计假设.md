# 残差诊断与统计假设

## 1. 残差不是误差

误差 $\varepsilon_i$ 不可观测；残差 $e_i=y_i-\hat y_i$ 是拟合后的估计。诊断残差是检查模型结构是否留下系统模式。

## 2. 四类诊断

| 图/检验 | 关注问题 |
|---|---|
| 残差—拟合值 | 非线性、异方差 |
| Q-Q 图 | 尾部、正态近似 |
| Scale-Location | 方差变化 |
| 杠杆/Cook 距离 | 高影响点 |
| Ljung-Box/DW | 有序残差自相关 |
| Breusch-Pagan | 异方差 |

## 3. Python 案例

```python
import matplotlib.pyplot as plt
import statsmodels.api as sm
from statsmodels.stats.diagnostic import (
    het_breuschpagan,
    acorr_ljungbox
)

resid = fitted.resid
fitted_values = fitted.fittedvalues

fig, axes = plt.subplots(1, 2, figsize=(10, 4))
axes[0].scatter(fitted_values, resid, alpha=0.6)
axes[0].axhline(0, color="black")
axes[0].set(xlabel="拟合值", ylabel="残差")
sm.qqplot(resid, line="45", ax=axes[1])
fig.tight_layout()
plt.show()

bp = het_breuschpagan(resid, fitted.model.exog)
print("BP p值:", bp[1])
print(acorr_ljungbox(resid, lags=[10], return_df=True))
```

## 4. 出现问题怎么办

- 非线性：变换、样条、多项式或树模型；
- 异方差：HC3/White 稳健标准误、变换、加权最小二乘；
- 自相关：时间结构、GLS、ARIMA 误差；
- 高影响点：核查、稳健回归、敏感性比较；
- 重尾：稳健标准误/Bootstrap/稳健损失。

White/HC3 只修正标准误，不修复遗漏变量、非线性或内生性。

## 5. 时间序列残差

白噪声核心是无系统自相关，正态性是预测区间的附加问题。不能用 Q-Q 图代替 Ljung-Box。

## 6. 论文表达

> 残差—拟合图未见明显曲线结构，但方差随拟合值略增，因此系数推断采用 HC3 稳健标准误。Ljung-Box 检验未发现显著残差自相关。删除高 Cook 距离点后的系数方向保持一致。

## 7. 易错点

- “检验不显著”就说假设完全成立。
- 对大样本依赖单一正态检验。
- 删除所有影响点。
- 把稳健标准误当作模型万能修复。
