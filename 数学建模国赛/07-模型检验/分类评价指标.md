# 分类评价指标

## 1. 混淆矩阵

|  | 预测正 | 预测负 |
|---|---:|---:|
| 实际正 | TP | FN |
| 实际负 | FP | TN |

$$
Precision=\frac{TP}{TP+FP}
$$

$$
Recall=\frac{TP}{TP+FN}
$$

$$
F1=\frac{2PR}{P+R}
$$

准确率在类别严重不平衡时可能误导。

## 2. Python

```python
from sklearn.metrics import (
    confusion_matrix,
    classification_report,
    roc_auc_score,
    average_precision_score
)

prob = model.predict_proba(X_test)[:, 1]
threshold = 0.5
pred = (prob >= threshold).astype(int)

print(confusion_matrix(y_test, pred))
print(classification_report(y_test, pred, digits=3))
print("ROC-AUC:", roc_auc_score(y_test, prob))
print("PR-AUC/AP:", average_precision_score(y_test, prob))
```

## 3. ROC-AUC 与 PR-AUC

- ROC-AUC：随机正样本得分高于随机负样本的概率解释。
- PR 曲线：关注正类预测的精确率与召回率；正类稀少时更有信息。
- AUC 不依赖单一阈值，但不能告诉实际阈值下的错误成本。

## 4. 阈值选择

根据验证集和业务代价选择：

- 疾病漏诊代价高：重召回；
- 告警过多成本高：重精确率；
- 可定义代价函数 $C_{FN}FN+C_{FP}FP$。

测试集不能用于选阈值。

## 5. 多分类

- macro：各类别等权，关注少数类；
- weighted：按样本数加权；
- micro：汇总全部决策。

论文必须说明采用哪种平均。

## 6. 概率校准

AUC 高不代表概率准确。若要解释“风险 80%”，应看校准曲线、Brier score，并可做概率校准。

## 7. 论文表达

> 正类比例仅……%，故不以准确率为主，而采用 PR-AUC 与宏平均 F1。阈值在验证集上按漏判成本……选择。测试集召回率为……、精确率为……，主要错误集中在……群体。

## 8. 易错点

- 用测试集选阈值。
- 不说明正类定义。
- 把 ROC-AUC 当准确率。
- 只报加权 F1 掩盖少数类失败。
